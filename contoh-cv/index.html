Studi kasus

Website CV Rizky Ardiansyah

Empat belas tahap kumulatif yang mengikuti slide Frontend Development dan Web Design. Setiap folder adalah website CV yang utuh pada tingkat kemampuan bab itu: buka dua folder berurutan untuk melihat persis apa yang ditambahkan satu pertemuan.

HTML dan CSS murni · Bootstrap 5.3.3 (CSS saja) mulai Bab 9 · tanpa JavaScript · konten berbahasa Indonesia

Cara membaca: folder tanpa CSS (Bab 1–2) masih polos dan itu memang tujuannya. Mulai Bab 3 gaya masuk lewat satu berkas css/style.css. Di Bab 9 tata letak pindah ke Bootstrap, dan berkas kustom menyusut jadi token, tipografi, serta overlay palet.
