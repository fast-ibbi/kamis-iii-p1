Rencana Belajar Rizky

Halaman ini melanjutkan profil saya. Isinya rencana lima pertemuan ke depan, ditulis sebelum praktikum dimulai.

Target Lima Pertemuan

  1. Menyusun kerangka semantik beranda dan halaman tentang.
  2. Memasang satu berkas CSS eksternal untuk seluruh halaman.
  3. Menata tipografi dan warna lewat design token.
  4. Menyusun kartu proyek dengan box model yang rapi.
  5. Merapikan navigasi dan footer dengan Flexbox.

Alat Kerja

  • VS Code dengan ekstensi Live Server
  • Google Chrome dan panel DevTools
  • Folder proyek cv-rizky/ di laptop

Cara Menilai Kemajuan

Setiap pertemuan, saya mencatat tiga baris di jurnal: apa yang dilihat, di panel apa, dan apa artinya bagi kode. Jurnal itu yang saya bawa saat konsultasi.
