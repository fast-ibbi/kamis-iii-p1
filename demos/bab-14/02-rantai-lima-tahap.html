Rantai Lima Tahap: Tiap Tahap Menambah Satu Lapis Keputusan

Desain yang rapi bukan hasil satu langkah. Ia lahir dari rantai lima tahap yang tidak boleh dibolak-balik: brief, arsitektur informasi, wireframe, UI design, lalu handoff. Implementasi biasanya jauh lebih cepat kalau keputusan desainnya sudah beres di depan.

Lima tahap berurutan

Setiap kotak berisi satu lapis keputusan yang nanti disalin ke kode. Kotaknya dirender dengan Flexbox sederhana, jadi rantainya tetap satu baris walau isinya berbeda panjang.

.rantai {
  display: flex;
  gap: 16px;
  align-items: stretch;
}

.rantai-tahap {
  box-sizing: border-box;
  flex: 1 1 0;
  padding: 12px;
  border-radius: 12px;
}

1 · Brief

Tujuan, audiens, dan konten.

2 · Arsitektur informasi

Sitemap halaman.

3 · Wireframe

Layout tanpa hiasan visual.

4 · UI design

Figma: warna dan ukuran.

5 · Handoff

Desain dibaca lalu diterjemahkan jadi kode.

Lima tahap membentuk empat celah: 64 px terpakai untuk jarak, sisanya dibagi rata oleh flex: 1 1 0.

Prototip bukan implementasi

Dua istilah ini paling sering tertukar di tugas. Prototip menjawab bentuk, implementasi menjawab perilaku. Yang diuji responsif adalah implementasinya, karena prototip cuma menirukan alur layar.

.pasangan {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 24px;
}

.pasangan-sisi {
  box-sizing: border-box;
  padding: 16px;
  border-radius: 12px;
}

Prototip Figma

  • simulasi interaktif desain
  • cepat dan murah diubah
  • menjawab bentuk
  • hanya hidup di Figma

Implementasi kode

  • tampilan di perangkat nyata
  • diubah lewat token yang tertata
  • menjawab perilaku
  • HTML semantik, CSS bertoken, komponen Bootstrap

Yang perlu diingat

  • Tahap yang paling sering dilewati tim kecil adalah wireframe, karena orang mau cepat masuk ke tampilan berwarna.
  • Interaktivitas berbasis JavaScript di luar cakupan mata kuliah ini, jadi keadaan seperti menu dan keranjang diterjemahkan sebagai tampilan statis.
  • Handoff menutup rantai: sesudahnya semua angka harus tertulis, bukan diingat.

Inti pembelajaran: kalau satu tahap dilompati, kekurangannya tidak hilang — ia muncul lagi di kode sebagai tebakan.
