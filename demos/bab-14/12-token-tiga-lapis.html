Token Tiga Lapis, Nama Mengikuti Peran

Token di proyek ini hidup di tiga lapis. Lapis satu adalah color style dan text style di Figma. Lapis dua adalah blok :root di css/style.css. Lapis tiga adalah pemakaiannya di kelas komponen lewat nilai token.

Tiga lapis untuk satu nilai

Model di bawah menyusun ketiga lapis dari atas ke bawah. Yang berpindah antarlapis cuma satu hal: nilai #4F46E5. Namanya berubah dari Warna/Primary jadi --clr-primary, lalu dipanggil var() di kelas komponen.

model spesifikasi · tiga lapis

Lapis 1 · Figma color style Warna/Primary #4F46E5 · text style Heading/Title 1
Lapis 2 · css/style.css :root { --clr-primary: #4F46E5; }
Lapis 3 · kelas komponen .produk-harga { color: var(--clr-primary); }

Satu blok diubah, semua komponen ikut

Aturan emasnya: nama variabel mengikuti peran, bukan warnanya. --clr-primary tetap masuk akal kalau indigo kelak diganti hijau. Contoh di bawah mengganti nilainya di satu tempat saja — kelas komponennya tidak disentuh.

:root {
  --clr-primary: #4F46E5;
}

.tema-ganti {
  --clr-primary: #16A34A;
}

.badge-lapis {
  background-color: var(--clr-primary);
  color: #FFFFFF;
}

Markup kedua badge itu sama persis; yang berbeda hanya nilai variabel pada pembungkusnya. Nilai hijau di sini contoh hipotetis — diambil dari --clr-success palet Tokosaya supaya tidak ada warna karangan baru.

Yang perlu diingat

  • Nilai token dipakai lewat CSS kustom; ia tidak menimpa utilitas Bootstrap diam-diam.
  • Menimpa variabel tema Bootstrap adalah pilihan resmi, tapi periksa nama variabelnya di dokumentasi versi 5.3 — namanya bisa berubah antarversi.
  • Kalau nilai yang sama dipakai lebih dari dua kali, ia layak jadi token.
  • Kalau nama token menyebut warna (--ungu), artinya perannya belum jelas.

Inti pembelajaran: tiga lapis ini yang membuat seluruh halaman bergerak barengan saat desain diperbarui. Cukup blok :root yang disalin ulang; nama kelas dan komponennya tidak perlu berubah.
