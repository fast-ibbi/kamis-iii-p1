Lima Langkah Translasi Komponen

Pola ini dipakai berulang untuk setiap komponen di produk.html: tulis tujuan komponennya, pilih elemen semantik, tentukan kelas Bootstrap, tulis CSS kustom bertoken, lalu bandingkan hasilnya dengan frame asli. Pakai utilitas Bootstrap dulu, lalu tambah CSS kustom secara terkontrol.

Lima langkah pada panel detail produk

Setiap baris di bawah adalah satu langkah, lengkap dengan keputusan nyata untuk panel P-DETAIL-01. Langkahnya tidak boleh diacak, karena langkah kelima yang memeriksa empat langkah sebelumnya.

.langkah-baris {
  display: flex;
  gap: 12px;
  align-items: flex-start;
}

.langkah-nomor {
  box-sizing: border-box;
  flex: 0 0 28px;
  padding: 4px 0;
  border-radius: 12px;
  text-align: center;
}

.langkah-isi {
  box-sizing: border-box;
  flex: 1 1 0;
  padding: 8px 0;
}

Hasil langkah dua sampai empat

Panel di bawah sudah memakai elemen semantik, susunan dari utilitas, dan CSS kustom yang hanya mengurus warna serta ukuran presisi. Warnanya datang dari blok :root yang dipetakan di halaman sembilan.

.panel-utama {
  display: flex;
  flex-direction: column;
  gap: 8px;
  align-items: flex-start;
}

.tombol-utama {
  box-sizing: border-box;
  padding: 12px 16px;
  border-radius: 12px;
}

Kenapa utilitas lebih dulu

  • Susunan tidak ditulis ulang, jadi CSS kustom tetap fokus ke warna serta ukuran presisi.
  • Kelas utilitas Bootstrap punya arti yang bisa dibaca di dokumentasi resmi versi 5.3.
  • Elemen semantik dipilih sebelum kelas: panel produk pakai <section> dengan <h2>.
  • Langkah terakhir membandingkan hasil dengan frame, bukan dengan perasaan.

Inti pembelajaran: pola lima langkah ini berulang untuk navbar, kartu, dan panel. Karena urutannya tetap, kesalahan paling sering ketahuan di langkah kelima — dan justru itu gunanya.
