Auto Layout Itu Flexbox

Auto layout di Figma menentukan arah anak — searah baris, kolom, atau keduanya — plus jarak antaranak dan padding di tepinya. Padanan CSS-nya sudah kamu pelajari di Bab 6: flex-direction menentukan arah, gap mengatur jarak.

Arah baris: baris kartu produk terkait

Di Figma, baris kartu produk terkait adalah auto layout searah baris. Di kode ia jadi baris Flexbox lewat d-flex dan gap. Karena angkanya dibaca dari panel desain, tidak ada jarak yang perlu ditebak.

.auto-baris {
  display: flex;
  gap: 24px;
  align-items: center;
}

.auto-kartu {
  box-sizing: border-box;
  flex: 1 1 0;
  padding: 12px;
  border-radius: 12px;
}

Padding 12 px di atas dan 12 px di bawah memakan 24 px tinggi tiap kartu, di luar tinggi isinya.

Arah kolom: panel harga

Panel harga di Figma juga auto layout, tapi searah kolom: badge, nama, kategori, harga. Di CSS arahnya cukup diganti flex-direction: column, dan jarak 8 px tetap satu angka yang sama.

.auto-kolom {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

Empat anak dengan tiga celah 8 px. Coba ganti flex-direction jadi row di DevTools: isi panel langsung berjajar ke samping, dan itu tanda arahnya memang ditentukan auto layout, bukan ukuran teks.

Inti pembelajaran: kamu tidak perlu menebak jaraknya, karena tinggal menyalin angka dari panel desain. Yang tetap berbeda hanya istilahnya — istilah Figma dan istilah CSS tidak pernah sama kata, walaupun maksudnya sama.
