Utilitas Dulu, Kustom Seperlunya

Prinsip kepalanya satu kalimat: tanya dulu apa Bootstrap sudah punya kelasnya; kalau ada, pakai kelas itu, dan jangan pernah berjuang melawan framework.

Empat utilitas yang paling sering dipakai

  • mb-3 buat jarak bawah, text-center buat perataan
  • d-none d-md-block menyembunyikan per bagian breakpoint
  • rounded-3 buat sudut bulat standar komponen
  • d-flex plus justify-content-between buat baris navigasi

Navbar Tokosaya tanpa satu aturan kustom

Navbar di bawah memakai satu kelas d-flex dengan justify-content: space-between. Brand selebar 160 px, empat menu masing-masing 120 px, dan gap 16 px. Wadahnya selebar kontainer Bootstrap 1120 px.

Aturan pelajaran untuk navbar: satu baris flex, jarak antar item, dan dua ukuran tetap.

.kontainer-navbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
  width: 1120px;
}

.merek {
  box-sizing: border-box;
  width: 160px;
  padding: 8px 12px;
  background: #eef2ff;
  border: 1px solid #c7d2fe;
  border-radius: 6px;
  font-size: 14px;
}

.menu-utilitas {
  box-sizing: border-box;
  width: 120px;
  padding: 8px 12px;
  background: #ffffff;
  border: 1px solid #d1d5db;
  border-radius: 6px;
  font-size: 14px;
  text-align: center;
}

Lebar wadah 1120 px mensimulasikan kontainer Bootstrap; kotak demo bergulir ke samping bila layarmu lebih sempit.

Isi navbar memakai 704 px dari 1120 px.

Sisa 416 px tidak dibiarkan menganggur: space-between yang membagikannya.

Lima item menghasilkan empat celah, jadi tiap celah bertambah 104 px — bukan dari margin per menu.

Aturan jaga dan batas praktis

  • Kustom dikasih komentar /* kustom */ biar kelihatan
  • Nilai kustom menumpang token, bukan hex acak
  • Jangan menimpa kelas baku Bootstrap pakai !important
  • Komponen interaktif butuh bundle JavaScript, di luar cakupan
  • CDN dikunci: Bootstrap 5.3.3 dan Bootstrap Icons 1.11.3
  • Ganti versi framework menjelang rilis bisa memicu regression
