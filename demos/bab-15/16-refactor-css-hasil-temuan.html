Kode: Refactor CSS Hasil Temuan

Blok SEBELUM cuma bahan diskusi review dan jangan dipertahankan di file riil. Yang dipertahankan hanya blok SESUDAH — satu aturan per maksud, nilai menumpang token, dan kaskade dibiarkan bekerja tanpa dipaksa.

Blok sebelum dan sesudah

/* ============ SEBELUM (bahan review) ============ */
/* kustom */
.card-produk-title { font-size: 22px; }

/* kustom */
div .card-produk-title { font-size: 20px !important; }

/* ============ SESUDAH (dipertahankan) ============ */
/* kustom — judul kartu produk; nilai mengikuti token */
.produk-card .card-title {
  font-size: 1.25rem;
  font-weight: 600;
  color: var(--clr-dark);
  border-radius: var(--radius);
}

File: tokosaya-bootstrap/css/style.css

  • Tiga aturan yang menyasar selector sama itu duplikasi
  • div menambah bobot, !important memaksa kemenangan

Hasil render keduanya

Judul di kedua panel tampak sama besar, tetapi sebabnya berbeda. Panel kiri menang karena !important memaksa; panel kanan menang karena hanya ada satu aturan yang menyasar judul itu.

sebelum

.card-produk-title { font-size: 22px; } div .card-produk-title { font-size: 20px !important; }

Dua puluh dua dan dua puluh hanya berjarak 2 px, tetapi keduanya berebut selector yang sama — itulah yang bikin kaskade perlu dibaca, bukan ditimpa.

Sesudah refactor nilainya ditulis 1.25rem, yang pada akar 16 px berarti 20 px — hasil yang sama, tanpa !important.

Tiga penyakit blok SEBELUM: duplikasi terpencar, !important, dan nilai acak di luar token. Setelah refactor, satu aturan per maksud, token yang memikul nilai, dan kaskade bekerja tanpa dipaksa — begitu juga cacat yang sama tidak lagi kambuh di halaman lain sebagai regresi.
