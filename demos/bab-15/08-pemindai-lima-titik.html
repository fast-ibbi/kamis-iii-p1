Pemindai Lima Titik

Pemindai lima titik adalah urutan tetap penyisiran satu halaman. Alatnya device toolbar di Chrome DevTools; yang dipindai selalu lima titik yang sama, halaman demi halaman, sambil menggeser lebar.

Lima titik, satu urutan

  • Navigasi — menu terbaca, link hidup, nggak meluber
  • Hero — judul dan tombol muat tanpa terpotong
  • Grid kartu — kolom berubah wajar, bukan menumpuk kacau
  • Form — label, input, dan tombol tersusun sejajar
  • Footer — link dan kontak tersusun kembali

Satu halaman, lima titik

Sembilan titik di bawah dibaca berurutan dari atas: navigasi, hero, tiga kartu produk, lalu form. Titik kelima, footer, sengaja diperiksa terakhir karena ia yang paling sering lupa diperbarui.

Aturan pelajaran untuk pemindai lima titik: grid 12 kolom, dua lebar tetap, dan penanda titik bernomor.

.baris-pindai {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 24px;
}

.pindai-penuh {
  grid-column: span 12;
}

.pindai-kartu {
  grid-column: span 4;
}

.titik-nomor {
  display: inline-block;
  width: 24px;
  height: 24px;
  margin-right: 8px;
  border-radius: 50%;
  background: #1d4ed8;
  color: #ffffff;
  font-size: 13px;
  font-weight: 600;
  text-align: center;
  line-height: 24px;
}

Tiga kartu selebar 4 kolom mengisi penuh 12 kolom, jadi baris kartu bisa diperiksa sebagai satu titik utuh.

Titik yang paling sering ditemukan bermasalah di proyek teman sekelas adalah grid kartu dan form. Tiap temuan sebaiknya disertai tangkapan layar, biar laporan QA punya bukti.
