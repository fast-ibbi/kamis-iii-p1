Struktur Folder Siap Tim

Folder proyek adalah dokumen arsitektur: orang yang baru bergabung bisa menebak jalan pikiran tim hanya dari pohonnya. Inilah pohon yang diserahkan sebagai paket rilis.

Pohon tokosaya-bootstrap/

tokosaya-bootstrap/
├── index.html
├── katalog.html
├── produk.html
├── kontak.html
├── checkout.html
├── styleguide.html
├── qa-checklist.html
├── laporan-temuan.html
├── css/
│   └── style.css
└── img/
    └── produk-keyboard-kx210.svg

Pohon yang sama dirender sebagai daftar di bawah, dengan tanda tingkat folder supaya batas antara isi proyek dan alat QA terlihat.

Aturan pelajaran untuk pohon folder: satu daftar tanpa penanda, dengan tiap tingkat menjorok 22 px.

.pohon {
  margin: 0;
  padding: 14px 16px;
  list-style: none;
  background: #ffffff;
  border: 1px solid #d1d5db;
  border-radius: 6px;
  font-family: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace;
  font-size: 13px;
  line-height: 1.75;
}

.pohon .anak {
  margin: 0;
  padding-left: 22px;
  list-style: none;
}

.pohon .folder {
  color: #1d4ed8;
  font-weight: 600;
}

.pohon .tanda {
  color: #6b7280;
}

Empat hal yang dibaca reviewer dari pohon ini:

  • HTML datar di akar — delapan halaman, tanpa subfolder halaman.
  • Satu folder css/ berisi style.css.
  • Satu folder img/ berisi gambar produk.
  • Alat QA di akar: qa-checklist.html dan laporan-temuan.html, biar reviewer cepat menemukannya.

Kalau ada berkas tambahan yang nyempil di luar pola ini, reviewer kehilangan tempat dan penyisiran jadi menyisakan lubang. Folder inilah yang dikunci sebagai paket rilis kandidat nanti.
