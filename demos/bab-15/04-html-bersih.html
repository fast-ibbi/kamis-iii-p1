HTML yang Bersih

Kode bersih punya dua pembaca: manusia dan mesin — browser, validator, dan pembaca layar. Enam aturan di bawah ini dipakai ulang sebagai butir checklist pada praktikum.

Enam aturan HTML bersih

  • DOCTYPE HTML5 plus lang="id" di elemen html
  • <meta name="viewport"> hadir di setiap halaman
  • Satu h1 per halaman, hierarki heading nggak melompat
  • Setiap img punya alt yang menjelaskan isinya
  • Setiap label terhubung ke input lewat for–id
  • Elemen semantik dipakai buat header, nav, main, dan footer

Label yang menyambung ke input

<label for="surel">Surel</label>
<input id="surel" name="surel" type="email">

Input surel di kontak.html nggak butuh CSS kustom. Di bawah, dua panel memakai medan yang sama persis; yang membedakan hanya pasangan for–id. Klik tulisan labelnya dan perhatikan ke mana fokus pindah.

Aturan pelajaran untuk medan surel: satu kotak dengan padding dan border yang bisa dihitung.

.medan-surel {
  box-sizing: border-box;
  width: 346px;
  height: 70px;
  padding: 12px;
  border: 1px solid #d1d5db;
  border-radius: 6px;
  font-size: 16px;
}

.label-terhubung {
  display: block;
  margin: 0 0 4px;
  font-size: 14px;
  font-weight: 600;
}

label terhubung

content 320 × 44 px

Klik tulisan Surel: kursor pindah ke kolom. Kotak putus-putus di atas adalah bagian content-nya, tanpa padding dan border.

label tanpa for

Klik tulisan Surel: kursor tidak pindah, dan pembaca layar menyebut medan ini "edit kosong".

Content 320 px, padding 12 px kiri–kanan, border 1 px kiri–kanan: lebar total 346 px.

Tinggi totalnya 70 px. Angka itu bukan inti halaman ini — yang bikin bersih adalah pasangan for–id, satu h1 per halaman, dan alt di setiap img.
