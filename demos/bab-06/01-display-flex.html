Bab 6 · Flexbox untuk Web Layout · 01 display flex

Wadah dan Butir Lentur

Flexbox ditulis pada elemen induk. Satu deklarasi di wadah mengubah semua anak langsungnya menjadi flex item, lalu wadah itu yang mengatur pembagian ruangnya.

Sebelum: tumpukan blok

Tanpa flexbox, tiap butir mengalir sebagai blok dan memakai satu baris penuh.

.nav-blok .butir {
  display: block;
}

wadah 720 px, tiap butir selebar 120 px

Merek
Menu
Keranjang

Tiga butir hanya memakai 120 × 3 = 360 px dari 720 px, tetapi tiap butir tetap memakan satu baris penuh.

Sesudah: display: flex

.site-nav {
  display: flex;
}

.site-nav .butir {
  width: 120px;
}

Elemen induk berubah menjadi flex container; merek, menu, dan keranjang langsung menjadi flex item yang mengalir pada satu jalur horizontal.

wadah 720 px, sumbu utama mendatar

Merek
Menu
Keranjang

Sisa 360 px di kanan belum dibagi ke mana pun; pembagiannya diatur properti container pada halaman berikut.

Yang berubah di HTML

  • Tidak ada satu baris HTML pun yang disentuh.
  • Hanya anak langsung yang menjadi flex item; cucu tetap mengikuti aturan blok biasa.
  • Properti container yang ditulis pada anak tidak berefek apa pun.
  • Kebiasaan block dan inline tidak lagi menentukan susunan.
