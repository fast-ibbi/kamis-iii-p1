Bab 6 · Flexbox untuk Web Layout · 04 justify-content

justify-content: Membagi Sisa Ruang di Sumbu Utama

Semua contoh di halaman ini memakai wadah 600 px berisi tiga butir 120 px. Isi memakai 360 px, jadi ada 240 px sisa yang menjadi bahan pembagian. Perhatikan ke mana sisa itu pergi pada tiap nilai.

flex-start — menempel di awal

.ke-awal {
  justify-content: flex-start;
}
Satu
Dua
Tiga

Sisa 240 px menganggur di kanan; tidak ada yang dibagikan.

flex-end — menempel di akhir

.ke-akhir {
  justify-content: flex-end;
}

Tiga

center — gugus di tengah

.ke-tengah {
  justify-content: center;
}
Satu
Dua
Tiga

space-between — tepi menempel, sisa di antara

.antara {
  justify-content: space-between;
}
Merek
Menu
Keranjang

Dua celah di antara tiga butir, masing-masing 120 px. Inilah pola navigasi Tokosaya: merek di kiri, keranjang di kanan.

Perhatikan bahwa butir pertama dan terakhir menempel tepat di tepi wadah: tidak ada sisa ruang di luar.

space-around — tiap butir berpeluk ruang

.disekitar {
  justify-content: space-around;
}
Satu
Dua
Tiga

Tiap butir dikelilingi ruang 80 px, sehingga celah antar butir 80 px.

Di tepi terluar hanya separuhnya: 40 px. Itu sebabnya tampilan space-around terasa tidak simetris.

space-evenly — semua celah sama besar

.merata {
  justify-content: space-evenly;
}
Satu
Dua
Tiga

Tiga butir menghasilkan empat celah yang sama besar: 60 px, termasuk dua celah di tepi.

Inti pembelajaran: justify-content hanya punya bahan untuk dibagikan kalau wadah lebih lebar daripada total isinya. Pada wadah yang sudah penuh, keenam nilai tampak sama.
