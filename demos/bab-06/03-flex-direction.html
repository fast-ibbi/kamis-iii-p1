flex-direction: Arah Main Axis

Empat nilai flex-direction hanya mengubah satu hal: ke mana main axis berjalan. Butir di bawah sengaja diberi nomor 1, 2, dan 3 sesuai urutan dokumen HTML, supaya terlihat mana yang berubah dan mana yang tidak.

row — kiri ke kanan, nilai default

.arah-row {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
}

Butir pertama menempel di awal baris, butir terakhir di akhir. Inilah nilai yang dipakai untuk menu dan baris kartu produk.

1Merek
2Menu
3Keranjang

Tiga butir memakai 360 px dari 720 px, jadi sisa 360 px dibagi dua celah oleh space-between.

Masing-masing celah 180 px.

row-reverse — kanan ke kiri

.arah-row-reverse {
  display: flex;
  flex-direction: row-reverse;
  justify-content: space-between;
}

Arah main axis dibalik, jadi titik awal baris berpindah ke kanan. Butir nomor 1 sekarang menempati ujung kanan, sedangkan urutan di dokumen HTML tetap 1, 2, 3.

1Merek
2Menu
3Keranjang

Jumlah ruang yang dipakai sama, 360 px sisa; yang berubah hanya dari ujung mana pembagian itu dimulai.

column — atas ke bawah

.arah-kolom {
  display: flex;
  flex-direction: column;
  justify-content: space-between;
}

Main axis berbalik menjadi vertikal. justify-content yang tadinya membagi ruang ke samping sekarang membagi ruang ke bawah, dan cross axis menjadi horizontal. Nilai ini yang dipakai untuk menumpuk isi di dalam kartu.

2Menu
3Keranjang

column-reverse — bawah ke atas

.arah-kolom-reverse {
  display: flex;
  flex-direction: column-reverse;
  justify-content: space-between;
}

Titik awal main axis pindah ke dasar wadah, jadi butir nomor 1 berada paling bawah. Dua varian reverse jarang dipakai di proyek nyata; gunanya lebih sering untuk percobaan daripada untuk layout sehari-hari.

Inti pembelajaran: mengganti flex-direction bukan sekadar membalik arah tampilan. Pekerjaan justify-content dan align-items ikut berpindah sumbu, jadi periksanya selalu berpasangan.
