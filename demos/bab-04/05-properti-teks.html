Properti Teks Setiap Hari

Lima properti yang paling sering dipakai untuk menata teks, beserta praktiknya di Tokosaya. Semuanya bekerja pada satu elemen yang sama.

Lima properti dan praktiknya

PropertiFungsiPraktik di Tokosaya
font-sizeukuran teksditulis memakai rem
font-weightketebalan teks400 isi, 600 subjudul, 700 judul
line-heighttinggi baris1,6 paragraf, 1,2 judul

Ukuran, ketebalan, dan jarak huruf

Deck hanya menyebut “sedikit negatif untuk judul besar”. Nilai negatif di bawah adalah peraga arah, bukan token Tokosaya; pasangan lebarnya dipakai supaya arahnya terlihat.

.judul-hero {
  font-size: 2.25rem;
  font-weight: 700;
  letter-spacing: -0.02em;
}

/* peraga arah: jarak huruf dilebarkan sebagai pembanding, bukan nilai Tokosaya */
.judul-lebar {
  font-size: 2.25rem;
  font-weight: 700;
  letter-spacing: 0.08em;
}

letter-spacing: -0.02em — judul besar dirapatkan

Belanja tepat, kirim cepat

letter-spacing: 0.08em — peraga pembanding

Belanja tepat, kirim cepat

Judul 2.25rem sama dengan 36 px pada basis 16 px.

Perataan teks

Isi rata kiri; center hanya dipakai di hero.

.hero-teks {
  text-align: center;
}

.isi-produk {
  text-align: left;
}

text-align: center — hanya di hero

Belanja tepat, kirim cepat

text-align: left — untuk isi

Paragraf isi dibaca lama, jadi perataan kiri menjaga tepi kiri baris tetap lurus dan mata tidak perlu mencari awal kalimat.

Cukup ditulis sekali

font-family, color, dan line-height diwariskan ke elemen anak, jadi html atau body cukup ditulis sekali.

.kutipan {
  font-family: 'Inter', sans-serif;
  color: #334155;
  line-height: 1.6;
}

Paragraf pertama mewarisi keluarga huruf, warna, dan tinggi baris dari kotak ini.

Anak di dalamnya juga: teks tebal ini hanya menambah ketebalan, tanpa menulis ulang keluarga huruf dan warnanya.
