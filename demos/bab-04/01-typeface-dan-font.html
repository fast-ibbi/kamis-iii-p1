Typeface dan Font

Typeface adalah keluarganya; font adalah satu wujud berat dan gaya di dalamnya. Salah menyebut tidak membuat kode error, hanya membuat diskusi tim berputar tanpa hasil.

Satu typeface, empat font

Poppins adalah keluarganya. Regular 400, Medium 500, SemiBold 600, dan Bold 700 adalah empat font di dalam keluarga yang sama; masing-masing punya berat sendiri.

.f-w400 {
  font-weight: 400;
}

.f-w500 {
  font-weight: 500;
}

.f-w600 {
  font-weight: 600;
}

.f-w700 {
  font-weight: 700;
}

Halaman ini tidak memuat web font, jadi keempat baris dirender oleh font sistem yang sama. Yang tetap terbaca sebagai pembeda adalah beratnya: itulah font. Nama keluarganya tetap satu, yaitu Poppins.

Berat yang dipakai Tokosaya

Isi memakai 400, subjudul 600, judul 700. Judul memakai Poppins 600 sampai 700, isinya memakai Inter 400.

.isi {
  font-family: 'Inter', sans-serif;
  font-weight: 400;
}

.subjudul {
  font-family: 'Poppins', sans-serif;
  font-weight: 600;
}

.judul {
  font-family: 'Poppins', sans-serif;
  font-weight: 700;
}

Judul hero Tokosaya

Subjudul bagian

Isi paragraf memakai Inter 400. Karena keluarga hurufnya tidak diunduh, bentuknya jatuh ke font sistem; yang tetap bekerja adalah berat 400 yang lebih ringan daripada dua baris di atasnya.

Dari 400 ke 700 ada jarak 300 satuan berat: dari isi yang tenang sampai judul yang tegas.
