Contrast Ratio dan Ambang AA

Contrast ratio mengukur seberapa kontras warna teks dibanding latarnya, dari 1:1 yang tidak terlihat sampai 21:1 untuk hitam di atas putih. WCAG 2.2 menetapkan ambang AA untuk teks.

Ambang AA

Jenis teksAmbang AA
teks ukuran normalminimal 4,5:1
teks besar sekitar 24pxcukup 3:1
batas bawah rentang1:1 — teks tidak terlihat
batas atas rentang21:1 — hitam di atas putih

Ambang AA memotong rentang itu: teks normal di bawah 4,5:1 gagal, teks normal minimal 4,5:1 lolos; teks besar 24 px cukup 3:1.

Lima pasangan palet Tokosaya

Empat pasangan lolos ambang 4,5:1. Hijau #16A34A di atas putih hanya 3,3:1, cukup untuk teks besar 24 px dan gagal untuk label 12 px.

:root {
  --clr-primary: #4F46E5;
  --clr-primary-dark: #4338CA;
  --clr-dark: #1E293B;
  --clr-body: #334155;
  --clr-success: #16A34A;
}

.teks-utama {
  color: var(--clr-dark);
  background-color: #FFFFFF;
}

.teks-isi {
  color: var(--clr-body);
  background-color: #FFFFFF;
}

.tautan {
  color: var(--clr-primary);
  background-color: #FFFFFF;
}

.tautan-hover {
  color: var(--clr-primary-dark);
  background-color: #FFFFFF;
}

.label-sukses {
  color: var(--clr-success);
  background-color: #FFFFFF;
}
Teks utama #1E293B di atas #FFFFFF lolos ambang 4,5:1
Teks isi #334155 di atas #FFFFFF lolos ambang 4,5:1
Tautan #4F46E5 di atas #FFFFFF lolos ambang 4,5:1
Tautan hover #4338CA di atas #FFFFFF lolos ambang 4,5:1
Label hijau #16A34A di atas #FFFFFF 3,3:1 — gagal untuk label kecil

Hijau murni kurang 1,2 dari ambang 4,5:1, jadi ia tidak boleh dipakai untuk label 12 px.

Teks besar sekitar 24 px

Pada ukuran besar, ambangnya turun ke 3:1, sehingga hijau 3,3:1 lolos di sana.

.label-besar {
  font-size: 24px;
}

.label-sukses {
  color: var(--clr-success);
  background-color: #FFFFFF;
}

Tint sebagai jalan keluar

Warna semantik dipindah ke latar tint, teksnya memakai warna gelap. Deck hanya menyebut “tint”; alfa 0,12 di bawah adalah nilai peraga supaya tintnya terlihat.

.badge-tint-sukses {
  background-color: rgba(22, 163, 74, 0.12);
  color: var(--clr-dark);
}

hijau murni sebagai latar, teks putih — 3,3:1
