Warna Semantik

Warna semantik membuat orang langsung memahami maknanya tanpa membaca teks. Hijau untuk status berhasil atau tersedia, merah untuk error atau stok habis, amber untuk hal yang perlu diperhatikan.

Satu warna, satu makna

Ketiga badge di kartu Tokosaya tidak menulis penjelasan apa pun: hijau #16A34A tersedia, amber #F59E0B Best Seller, indigo #4F46E5 Baru. Merah #DC2626 dipakai untuk stok habis.

:root {
  --clr-primary: #4F46E5;
  --clr-accent: #F59E0B;
  --clr-success: #16A34A;
  --clr-danger: #DC2626;
}

.badge-tersedia {
  background-color: var(--clr-success);
  color: #FFFFFF;
}

.badge-bestseller {
  background-color: var(--clr-accent);
  color: #FFFFFF;
}

.badge-baru {
  background-color: var(--clr-primary);
  color: #FFFFFF;
}

.badge-habis {
  background-color: var(--clr-danger);
  color: #FFFFFF;
}

Tersedia Best Seller Baru Stok habis

Maknanya terbaca sebelum teksnya. Warna hiasan bekerja sebaliknya: warnanya dipilih supaya ramai, tidak ada makna yang menempel, dan status harus ditulis dan dibaca.

Komponen memakai var(--clr-success), bukan #16A34A. Kalau muncul status kelima, ia harus lebih dulu diberi makna di palet — warna di luar palet tidak dipakai tanpa alasan.

Catatan kontras label kecil

Label di atas memakai teks putih pada latar hijau murni. Hijau #16A34A di atas putih hanya 3,3:1 — angka ini dibahas di halaman 11: cukup untuk teks besar, gagal untuk label kecil. Jalan keluarnya sama seperti di Cek Daftar: badge memakai tint sebagai latar dan teks gelap sebagai warnanya.
