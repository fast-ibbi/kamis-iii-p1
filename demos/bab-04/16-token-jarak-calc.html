Token Jarak dan calc()

Satu token jarak menjadi basis seluruh ritme halaman. calc() mengalikannya dengan bilangan bulat, sehingga jarak apa pun tetap kelipatan 8 px.

Satu basis, semua jarak

--space-unit: 8px menjadi basis semua jarak di halaman. Padding section dikalikan tujuh untuk atas-bawah dan empat untuk kiri-kanan.

:root {
  --space-unit: 8px;
}

.section {
  padding: calc(var(--space-unit) * 7) calc(var(--space-unit) * 4);
}
Isi section. Ruang di sekeliling kotak ini adalah padding hasil calc(): 56 px atas dan bawah, 32 px kiri dan kanan.

Atas dan bawah: 8 × 7 = 56 px.

Kiri dan kanan: 8 × 4 = 32 px.

Kelipatan 8 px

Skala jarak Tokosaya mengikuti kelipatan 8 piksel dari 8 sampai 64 piksel.

KelipatanNilaiContoh pemakaian
1 ×8 pxjarak antarbadge
2 ×16 pxjarak di dalam kartu
3 ×24 pxpadding kartu
4 ×32 pxsisi section
7 ×56 pxatas dan bawah section
8 ×64 pxjarak antarsection

lebar batang sebanding nilainya

Batang terpanjang adalah kelipatan delapan: 64 px.

Penamaan dan pemakaian

  • Penamaan kebab-case: --clr- untuk warna, --font- untuk tipografi.
  • Token hanya untuk nilai yang berulang; token berlebihan sama buruknya dengan warna yang berantakan.
  • Seluruh ritme jarak halaman mengikuti kelipatan 8 px, jadi tidak ada angka liar di komponen.

Token --space-unit mulai bekerja penuh di Bab 5, dan skala serta token di bab ini dipakai hingga bab akhir.
