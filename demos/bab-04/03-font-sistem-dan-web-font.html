Font Sistem dan Web Font

Browser memakai font sistem bawaan, bukan pilihan kita; karena itu Windows, macOS, dan Android menampilkan keluarga font yang berbeda. Web font adalah keluarga huruf yang diunduh saat halaman dibuka, jadi bentuk huruf tidak lagi ditentukan perangkat.

Tiga permintaan, satu hasil di mesin ini

Ketiga baris di bawah meminta keluarga huruf yang berbeda. Tidak satu pun berkas font itu diunduh oleh halaman ini, sehingga browser turun ke kategori generik di ujung setiap stack.

.tanpa-poppins {
  font-family: 'Poppins', sans-serif;
}

.tanpa-inter {
  font-family: 'Inter', sans-serif;
}

.tanpa-lokal {
  font-family: 'Helvetica Neue', sans-serif;
}

Poppins untuk judul: Belanja tepat, kirim cepat

Inter untuk isi: Halaman yang sama, dua perangkat, bisa terlihat seperti dua situs yang berbeda.

Helvetica Neue di perangkat lain: Belanja tepat, kirim cepat

Ketiganya tampak sama karena di mesin ini ketiganya berakhir di font sistem yang sama. Itulah yang dilihat pengunjung ketika web font gagal diunduh: teksnya tetap terbaca, tetapi identitas brand hilang. Karena itu halaman tetap harus terbuka saat font gagal diunduh.

Memuat Google Fonts

Tiga tag berikut ditulis di dalam <head>. Halaman demo ini sengaja tidak memuat aset luar apa pun, jadi blok di bawah ditampilkan sebagai kode dan seluruh teks di halaman ini dirender oleh font stack sistem.

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;500;600;700&family=Inter:wght@400;500;600&display=swap">
  • Dua preconnect menyiapkan koneksi ke server font sejak awal.
  • family= meminta keluarga huruf sekaligus daftar ketebalannya.
  • display=swap menampilkan font cadangan untuk sementara.
  • URL ini disalin persis dan tidak boleh diketik ulang; satu karakter berbeda membuat font tidak termuat.

Kerangka index.html

File HTML-nya hanya bertambah beberapa baris dari Bab 3, dan semuanya berada di dalam <head>.

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tokosaya — Belanja Tepat, Kirim Cepat</title>
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link rel="stylesheet" href="css/style.css">
</head>

css/style.css dimuat setelah tag font supaya gaya kita sendiri dievaluasi belakangan, sehingga keputusan kita yang menang. Di halaman hasilnya nanti, h1 hanya satu dan heading turun level tanpa melompat.
