Palet Tokosaya

Tiap warna punya satu peran; di luar lima kartu ini warna tidak dipakai tanpa alasan. Indigo memimpin, amber menyorot, slate menopang, hijau dan merah berbicara.

Lima peran, satu palet

:root {
  --clr-primary: #4F46E5;
  --clr-primary-dark: #4338CA;
  --clr-accent: #F59E0B;
  --clr-dark: #1E293B;
  --clr-border: #E2E8F0;
  --clr-success: #16A34A;
  --clr-danger: #DC2626;
}

Kartu netral sengaja digambar sebagai gradient karena dipakai berjenjang, bukan satu warna tunggal. Tempel palet ini di folder proyek; paletnya terkunci, jadi warna di luar kartu tidak dipakai tanpa alasan.

Warna utama gelap dipakai saat tombol di-hover

.tombol {
  background-color: var(--clr-primary);
  color: #FFFFFF;
}

.tombol:hover {
  background-color: var(--clr-primary-dark);
}

arahkan penunjuk ke tombol: latarnya berpindah dari #4F46E5 ke #4338CA
