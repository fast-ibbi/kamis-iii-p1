Skala Tipografi Tokosaya

Skala tipografi mengubah tebakan ukuran menjadi keputusan yang dapat diulang. Satuan rem mengikuti ukuran font akar html; basisnya 16 px.

Tanpa skala: 19, 21, dan 23 px

Setiap judul ditulis dengan ukuran yang asal — 19px di sini, 21px di sana, 23px di tempat lain — sehingga pembaca tidak menemukan pintu masuk halamannya.

.judul-19 {
  font-size: 19px;
}

.judul-21 {
  font-size: 21px;
}

.judul-23 {
  font-size: 23px;
}

Cara memesan

Ketiganya nyaris sama besar, jadi tidak ada yang terbaca sebagai kepala bagian. Yang diperbaiki lebih dulu adalah kebiasaan menebak ukuran, bukan angkanya satu per satu.

Dengan skala: rem pada basis 16 px

Skala Tokosaya punya sembilan tingkat. Deck menyebut nama Display, Heading 1, dan Label; tingkat di antaranya mengisi jarak keduanya, dan isi memakai 1rem.

.display {
  font-size: 3rem;
  font-weight: 700;
}

.heading-1 {
  font-size: 2.25rem;
  font-weight: 700;
}

.isi-skala {
  font-size: 1rem;
}

.label {
  font-size: 0.75rem;
}

Display 3rem · 48 px

Heading 1 2.25rem · 36 px

Isi 1rem · 16 px

Label 0.75rem · 12 px

Display 3rem pada basis 16 px adalah 48 px.

Heading 1 2.25rem adalah 36 px.

Label 0.75rem adalah 12 px — memang sekecil itu, seperti pada diagram deck yang digambar seukuran aslinya.

Nama levelnya yang dipakai saat berdiskusi dengan desainer, bukan angkanya. Skala inilah yang menopang hierarki visual nanti.
