Blok Design Token Tokosaya

Design token mengumpulkan semua keputusan warna, tipografi, sudut, dan bayangan menjadi CSS custom property di :root. Blok ini dipakai apa adanya di seluruh proyek.

Blok lengkapnya

Buka file aslinya di editor: blok ini duduk di awal style.css dan dipakai apa adanya di seluruh proyek.

:root {
  --clr-primary: #4F46E5;
  --clr-primary-dark: #4338CA;
  --clr-accent: #F59E0B;
  --clr-dark: #1E293B;
  --clr-body: #334155;
  --clr-bg: #F8FAFC;
  --clr-surface: #FFFFFF;
  --clr-border: #E2E8F0;
  --clr-success: #16A34A;
  --clr-danger: #DC2626;
  --font-heading: 'Poppins', sans-serif;
  --font-body: 'Inter', sans-serif;
  --radius: 12px;
  --shadow-card: 0 8px 24px rgba(15, 23, 42, 0.08);
  --space-unit: 8px;
}
--clr-primary
--clr-primary-dark
--clr-accent
--clr-dark
--clr-body
--clr-bg
--clr-surface
--clr-border
--clr-success
--clr-danger

Nama mengungkap peran: --clr-primary, bukan --indigo. Mengganti warna brand tidak membuat namanya bohong.

Dipakai lewat var()

.tombol {
  background-color: var(--clr-primary);
  color: var(--clr-surface);
}

.kartu-token {
  background-color: var(--clr-surface);
  border: 1px solid var(--clr-border);
  border-radius: var(--radius);
}

Kartu dengan latar var(--clr-surface) dan garis var(--clr-border).

Salah ketik satu karakter pada nama token membuat seluruh warnanya kembali abu-abu.

Tipografi dari token

Di deck, aturan pertama dipasang pada html; di halaman ini ia dipasang pada pembungkus .d-token agar tipografi demo tidak ikut berubah.

/* aturan html di deck dipindahkan ke pembungkus .d-token agar tipografi
   halaman demo tidak ikut berubah */
.d-token {
  font-family: var(--font-body);
  color: var(--clr-body);
  background-color: var(--clr-bg);
  line-height: 1.6;
}

.d-token h3 {
  font-family: var(--font-heading);
  color: var(--clr-dark);
  line-height: 1.2;
}

.d-token a {
  color: var(--clr-primary);
  text-decoration: none;
}

Belanja tepat, kirim cepat

Di blok ini tidak ada satu pun kode heksadesimal warna; semuanya lewat var(). Lihat halaman palet untuk peran tiap warna.

Di luar :root, hanya #FFFFFF yang ditulis langsung; nilai lain selalu lewat token.
