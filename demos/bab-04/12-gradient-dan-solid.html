Solid dan Gradient

Permukaan yang dibaca lama lebih nyaman jika datar. Gradient dipakai seperti bumbu: satu atau dua titik per halaman, bukan di setiap kartu.

Permukaan membaca dan permukaan menyambut

:root {
  --clr-surface: #FFFFFF;
}

.produk-card {
  background-color: var(--clr-surface);
}

.hero {
  background-image: linear-gradient(to bottom right, #4F46E5, #4338CA);
}

Aturan pemakaiannya

  • to bottom right berjalan dari kiri atas ke kanan bawah.
  • Gradient dipakai seperti bumbu: satu atau dua titik per halaman.
  • Periksa contrast ratio teks di atasnya, jangan hanya melihat gradient-nya.
  • Di halaman Tokosaya, gradient hanya muncul di hero, CTA, dan footer.
