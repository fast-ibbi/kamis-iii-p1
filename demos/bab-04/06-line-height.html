Line-height: Nilai Tanpa Satuan

line-height menentukan tinggi satu baris teks. Angka tanpa satuan berarti kelipatan ukuran font elemen itu sendiri, jadi nilainya ikut membesar saat font diperbesar.

Tiga kerapatan

Teks yang sama dibaca pada tiga nilai. Teks panjang nyaman di 1,5–1,7; judul besar tegas di 1,1–1,25. Nilai 1,2 dipakai judul di Tokosaya, 1,6 dipakai paragraf.

.rapat {
  line-height: 1.2;
}

.nyaman {
  line-height: 1.6;
}

.longgar {
  line-height: 2;
}

line-height: 1.2

Teks yang ditata rapat membuat mata berpindah baris terlalu cepat sehingga pembaca kehilangan tempatnya di tengah kalimat yang panjang.

Satu baris teks 1rem dengan line-height: 1.6 tingginya 25,6 px.

Angka tanpa satuan ikut membesar, 24px mengunci

1,6 berarti 1,6 kali ukuran font elemen itu sendiri. Angka tanpa satuan ikut membesar saat pengguna memperbesar font di pengaturan browser; 24px mengunci jaraknya.

.kunci {
  line-height: 24px;
}

.ikut {
  line-height: 1.5;
}

Judul

font-size 2.25rem — line-height: 1.5

Judul

Pada 1rem, line-height: 1.5 kebetulan sama dengan 24 px, sehingga kedua kolom atas tampak sebangun.

Pada 2.25rem atau 36 px, angka 1,5 menjadi 54 px, sedangkan 24 px tetap 24 px — itulah bedanya.
