Fallback Stack Wajib Ada

Stack adalah daftar cadangan, bukan daftar pilihan. Browser membacanya dari kiri ke kanan; jika Inter gagal dimuat, ia pindah ke sans-serif perangkat.

Stack untuk badan dan judul

Nama font yang mengandung spasi dibungkus tanda kutip, dan stack selalu ditutup dengan kategori generik. Di deck, aturan pertama dipasang pada html; di halaman ini ia dipasang pada pembungkus .d-stack supaya tipografi demo tidak ikut berubah.

/* aturan html di deck dipindahkan ke pembungkus .d-stack agar tipografi
   halaman demo tidak ikut berubah */
.d-stack {
  font-family: 'Inter', sans-serif;
}

.d-stack h3 {
  font-family: 'Poppins', sans-serif;
}

Poppins untuk judul, Inter untuk isi

Kedua keluarga huruf di atas tidak diunduh halaman ini, jadi keduanya berhenti di sans-serif perangkat. Teksnya tetap terbaca — itulah tugas stack.

Minta satu layar mematikan akses internet lalu memuat ulang halaman; hasilnya kurang lebih seperti kotak ini.

Versi yang salah, lalu diperbaiki

Tanpa tanda kutip dan tanpa fallback, keluarga huruf hanya satu nama. Kalau nama itu tidak ada di perangkat, browser memakai font bawaannya — dan hasilnya baru ketahuan di komputer orang lain.

.rusak {
  font-family: Poppins;
}

.benar {
  font-family: 'Poppins', sans-serif;
}

font-family: Poppins;

Belanja tepat, kirim cepat

font-family: 'Poppins', sans-serif;

Belanja tepat, kirim cepat

Kedua baris di atas masih tampak sama di mesin ini, karena Poppins memang tidak terpasang. Perbedaannya baru terlihat pada perangkat yang punya Poppins: baris pertama akan menemukannya, baris kedua memakai Poppins yang diunduh web font, dan keduanya sama-sama punya jalan keluar ke sans-serif bila gagal.
