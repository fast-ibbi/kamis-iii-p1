Tangga Breakpoint Tokosaya

Breakpoint lahir dari kebutuhan konten, bukan dari daftar HP di toko. Tangga di bawah dibaca dari kiri ke kanan: makin lebar layarnya, makin banyak kolom katalog yang masuk.

Tangga lima anak

Lebar tiap wadah mensimulasikan viewport, sedangkan nama anak tangganya mengikuti skala Bootstrap 5.3. Angka di tiap label tetap angka aslinya — mulai 0, 576, 768, 992, dan 1200 px — hanya tampilannya yang diperkecil menjadi 0,7 supaya keenam baris muat di kolom isi.

Perhatikan jumlah kolom dan keadaan navigasi di tiap anak tangga. Baris terlebar 1200 px, jadi seluruh tangga ditampilkan pada skala 0,7.

Di lg, empat kolom bergutter 16 px jadi 236 px per kartu.

Di xl, kolomnya tetap empat, hanya lebarnya naik jadi 288 px.

Satu strategi ditulis di kepala berkas

Proyek Tokosaya cuma memilih dua anak tangga: md 768 dan lg 992. Dua angka itu yang muncul di media query kustom, dan keputusannya ditulis sebagai komentar di atas berkas supaya enam bulan lagi masih terbaca.

/* ============================================================
   Tokosaya — css/style.css (versi Bab 13)
   Strategi breakpoint: base (< 768px), md 768px, lg 992px
   (selaras dengan Bootstrap 5.3)
   ============================================================ */
.katalog {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

@media (min-width: 768px) {
  .katalog {
    grid-template-columns: repeat(3, 1fr);
  }
}

@media (min-width: 992px) {
  .katalog {
    grid-template-columns: repeat(4, 1fr);
  }
}

Kelas Bootstrap col-md-4 dan col-lg-3 ikut bicara 768 dan 992. Kalau CSS kustom memakai 700 px, ada dua strategi yang bertabrakan dan layout berubah di tempat yang tidak terdokumentasikan. Itu sebabnya 578px, 693px, dan 1024px disebut angka ajaib: angkanya tidak menceritakan maksud apa pun dan tidak selaras dengan Bootstrap.

Urutan tautan stylesheet juga ikut menentukan: Bootstrap dulu, CSS kustom setelahnya.
