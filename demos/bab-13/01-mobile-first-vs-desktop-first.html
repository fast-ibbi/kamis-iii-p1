Mobile-First dan Desktop-First: Dua Arah Menulis Media Query

Keduanya sama-sama sah. Yang membedakan cuma arah berpikirnya: dari layar kecil melebar, atau dari layar besar menyempit. Halaman ini memperlihatkan keduanya berdampingan, lengkap dengan risiko yang dijaga masing-masing.

Contoh yang memicunya: kartu 320 px di layar 360 px

Kartu katalog Tokosaya punya content 280 × 96 px untuk gambar produk, padding 16 px, dan border 4 px. Dengan box-sizing: border-box, lebarnya jadi 320 px — rapi di monitor, tetapi dua kartu langsung meluber di layar HP.

.kartu {
  box-sizing: border-box;
  width: 320px;
  padding: 16px;
  border: 4px solid #e5e7eb;
}

Wadah di bawah selebar 360 px — lebarnya mensimulasikan viewport HP, bukan lebar jendela peramban.

Mobile-first: gaya dasar layar kecil, min-width menaik

Gaya dasar ditulis untuk layar kecil. Media query min-width tinggal menambah, bukan menimpa, jadi tidak ada aturan yang saling berkelahi.

.katalog {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

@media (min-width: 768px) {
  .katalog {
    grid-template-columns: repeat(2, 1fr);
  }
}

Dua wadah berdampingan. Lebar keduanya mensimulasikan viewport, jadi hasil media query-nya dipatok per wadah.

Desktop-first: gaya dasar layar besar, max-width menurun

Kebalikannya. Gaya dasar ditulis untuk layar besar, lalu media query max-width merapikan tampilan sempit. Cocok untuk dashboard staf dan data padat.

.panel-admin {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 16px;
}

@media (max-width: 767px) {
  .panel-admin {
    grid-template-columns: 1fr;
  }
}
