Skip Link: Link Pertama di Body

Skip link adalah tautan pertama di dalam body, jadi elemen pertama yang menerima fokus saat Tab ditekan. Posisinya bukan pilihan gaya, melainkan syarat. Ini susunan yang sesuai kriteria bypass blocks pada WCAG.

Markup-nya

<a class="skip-link" href="#konten-utama">Lewati ke konten utama</a>

Sasar lompatannya adalah konten utama. Di demo ini tautannya diarahkan ke berkas demo lain supaya tetap bisa diklik; di proyek Tokosaya tujuannya #konten-utama, dan di bawah ini sasaran itu ditandai menerima fokus.

<main id="konten-utama" tabindex="-1">

tabindex="-1" membuat main bisa menerima fokus dari lompatan, tanpa ikut masuk urutan Tab biasa.

CSS-nya: muncul pas fokus

.skip-link {
  position: absolute;
  top: -48px;
  left: 16px;
  z-index: 1080;
  background: var(--clr-primary-dark);
  color: #fff;
  padding: 10px 16px;
  border-radius: 0 0 8px 8px;
  text-decoration: none;
  transition: top 0.15s ease-in-out;
}
.skip-link:focus { top: 0; }

Normalnya link disembunyikan di atas layar lewat top: -48px, lalu turun ke top: 0 saat menerima fokus. Jangan pakai display: none atau visibility: hidden: elemen yang disembunyikan begitu tidak bisa menerima fokus, jadi pengguna keyboard tidak akan pernah sampai ke sana.

Tiga hal yang harus pas

SyaratKalau salah
ditaruh paling awal di dalam bodybukan fokus pertama, jadi tidak menolong siapa pun
nama kelas HTML dan CSS identiksalah ketik satu huruf membuat link tidak pernah muncul
z-index cukup tinggitertutup elemen lain, linknya tidak kelihatan meski fokus sudah pindah

Ujinya selalu dengan keyboard, bukan klik: klik tidak akan menyingkap masalah fokus. Tekan Tab satu kali, pastikan link muncul, lalu Enter — fokus harus pindah ke konten utama.
