Navigasi Menumpuk Tanpa Skrip

Pola menumpuk tidak butuh ikon hamburger. Di layar kecil daftar link ditumpuk vertikal, di tablet ke atas menjadi satu baris. Semuanya CSS murni: satu properti flex-direction yang berganti di 768 px.

Aturannya

/* mobile: menu menumpuk lebar penuh */
.site-nav ul { flex-direction: column; align-items: flex-start; }

@media (min-width: 768px) {
  /* tablet & lebih: menu horizontal satu baris */
  .site-nav ul {
    flex-direction: row;
    align-items: center;
    gap: 1.5rem;
  }
}

Tidak ada ikon hamburger, jadi tidak ada skrip yang perlu dimuat. Link juga tetap jadi target sentuh penuh di layar kecil, bukan teks kecil yang berdesakan.

Hasil yang dirender

Lebar tiap wadah di bawah mensimulasikan viewport, sedangkan keadaan menunya dipatok per wadah.

Di proyek tiap tautan menuju halamannya sendiri; di demo ini semuanya menuju berkas demo lain supaya tetap bisa difokuskan dan diklik dengan Tab. Panel 992 px ditampilkan pada skala 0,85 supaya muat di kolom isi; angka breakpoint-nya tetap 992 px.
