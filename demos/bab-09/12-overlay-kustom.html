Overlay CSS Kustom: Dua Token di Atas Bootstrap

Overlay adalah lapisan CSS kecil milik sendiri yang dimuat setelah Bootstrap. Isinya bukan menimpa semua kelas, melainkan menggeser beberapa variabel yang sudah dibaca Bootstrap. Cuplikan dari deck dipakai apa adanya di bawah ini.

Cuplikan overlay

/* kustom — overlay dua token utama Tokosaya di atas Bootstrap */
:root {
  --clr-primary: #4F46E5;
  --clr-primary-dark: #4338CA;
  /* menyelaraskan warna primary Bootstrap (kelas text-*, bg-*) */
  --bs-primary-rgb: 79, 70, 229;
}

/* tombol utama Tokosaya dibentuk dari kelas btn + kelas kustom */
.btn-tokosaya {
  background-color: var(--clr-primary);
  border-color: var(--clr-primary);
  color: #FFFFFF;
}

Bacanya baris demi baris. --clr-primary menyimpan indigo Tokosaya dan --clr-primary-dark varian gelapnya. --bs-primary-rgb menuliskan warna yang sama dalam bentuk RGB — 4F jadi 79, 46 jadi 70, E5 jadi 229 — karena kelas text-* dan bg-* Bootstrap memakai bentuk itulah untuk menghitung transparansi.

Hasilnya di dua panel

Tanpa overlay

teks primary — biru bawaan

Tombol ini memakai kelas bawaan btn-primary.

Dengan overlay Tokosaya

teks primary — indigo Tokosaya

Tombol ini memakai btn ditambah kelas kustom btn-tokosaya.

<button class="btn btn-tokosaya">Tambah ke keranjang</button>

Perhatikan satu hal yang sering terlewat: btn-primary di panel kanan tetap biru. Warna tombol bawaan Bootstrap disimpan di variabel lain, jadi menggeser --bs-primary-rgb tidak menyentuhnya. Karena itulah tombol khas Tokosaya sengaja dibentuk sebagai kelas kustom yang eksplisit — bukan menunggu variabel tema yang bisa bergeser antar rilis.

Kenapa css/style.css dimuat paling belakang

Pada specificity yang setara, aturan yang termuat belakangan menang. Halaman ini memakai aturan yang sama: berkas Bootstrap dimuat lebih dulu, lalu blok gaya halaman menyusul. Kalau urutannya dibalik, deklarasi di atas kalah oleh pustaka dan tombolnya kembali biru.
