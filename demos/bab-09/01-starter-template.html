Starter Template 5.3.3: Urutan Link yang Dijaga

Bootstrap dimuat lewat satu baris <link> di kepala halaman, sebelum CSS kustom. Di kelas, berkasnya diambil dari folder _vendor/ supaya demo tetap jalan tanpa internet; alamat CDN yang dipakai slide praktikum ditulis di bagian bawah halaman ini.

Kepala halaman

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Tokosaya — Belanja Tepat, Kirim Cepat</title>
  <!-- Bootstrap 5.3.3 — CSS (di kelas: ../_vendor/bootstrap.min.css) -->
  <link rel="stylesheet" href="../_vendor/bootstrap.min.css">
  <!-- Bootstrap Icons 1.11.3 -->
  <link rel="stylesheet" href="../_vendor/bootstrap-icons.min.css">
  <!-- Tanpa bootstrap.bundle (JavaScript di luar cakupan mata kuliah) -->
  <!-- CSS kustom Tokosaya — selalu dimuat setelah Bootstrap -->
  <link rel="stylesheet" href="css/style.css">
</head>

Urutannya dijaga: Bootstrap, Icons, Fonts, lalu kustom. css/style.css paling belakang supaya menang di kaskade ketika specificity-nya setara.

Tombol uji: tanda stylesheet termuat

<button type="button" class="btn btn-primary">
  <i class="bi bi-cart"></i> Tambah ke keranjang
</button>

Kalau tombol di atas tampil biru dengan sudut membulat dan ikon keranjang muncul, kedua berkas termuat. Tombol biru itu warna primary bawaan Bootstrap — bukan indigo Tokosaya.

Dua cara memperoleh pustaka

https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css
  • Unduh filenya lalu simpan di folder proyek: dipakai demo di halaman ini.
  • Atau pasang link langsung dari server CDN: praktis, tapi butuh jaringan internet.
  • Nilai integrity pada versi CDN perlu dicek di dokumentasi resmi untuk website sungguhan.

Bagian paket yang dipakai

Satu paket Bootstrap 5.3.3 berisi dua bagian. Bagian CSS menyumbang grid 12 kolom dan komponen seperti navbar; bagian JavaScript dikemas di berkas bootstrap.bundle dan tidak dimuat sama sekali di buku ini. Halaman ini hanya memuat dua berkas CSS dari _vendor/.

Inti pembelajaran: satu baris <link> sudah memindahkan ratusan aturan siap pakai ke halaman, dan urutan pemuatan berkas menentukan siapa yang menang saat aturannya bertabrakan.
