Komponen dan Matriks Varian

Komponen adalah unit antarmuka yang diulang; varian adalah wujud bakunya. Matriks varian ditulis supaya varian aneh bisa dikenali sejak awal dan nggak lolos ke produksi tanpa alasan.

Matriks varian tombol

Tiga varian, tiga status. Arahkan kursor ke tombol normal untuk melihat status hover yang sesungguhnya; tombol paling kanan memakai atribut disabled untuk status nonaktif.

Kartu produk: enam bagian, urutan tetap

Enam bagian tetap: badge status, ikon, judul, keterangan, harga, dan aksi. Varian dibedakan lewat isi, bukan lewat wajah; kartu Best Seller dan Stok Terbatas berbagi kelas p-kartu yang sama.

Badge ikut punya aturan

Setiap badge dataset punya satu token tetap. Warna bukan satu-satunya penyampai makna, jadi teks di dalam badge harus tetap menjelaskannya.

.badge-dataset {
  box-sizing: border-box;
  display: inline-block;
  padding: 2px 8px;
  border-radius: 999px;
  font-size: 12px;
  color: #FFFFFF;
}

.badge-bestseller {
  background: var(--clr-accent);
}

.badge-tersedia {
  background: var(--clr-success);
}

.badge-terbatas {
  background: var(--clr-danger);
}

.badge-baru {

Yang perlu diingat

  • Utama buat satu tindakan paling bernilai di layar.
  • Outline urutan kedua; netral buat tindakan pendamping.
  • Varian di luar matriks nggak boleh lolos ke produksi.
  • Badge kecil pun masuk matriks varian dan harus ada di styleguide.

Inti pembelajaran: matriks varian bukan formalitas. Ia yang membuat "tombol ini kok beda?" bisa dijawab dengan menunjuk satu baris tabel, bukan dengan selera.
