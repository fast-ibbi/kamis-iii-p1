Empat Lapisan Design System: Token, Komponen, Halaman

Setiap lapisan dipakai lapisan di atasnya. Token menyediakan nilai, komponen mengonsumsi nilai itu, halaman mengonsumsi komponen, dan pengguna akhirnya melihat halamannya. Pola dan dokumentasi melengkapi dua lapisan sisanya.

Lapisan 1 — token

Semua keputusan visual tinggal di satu blok :root di paling atas css/style.css. Tidak ada halaman yang boleh menulis nilai mentah.

:root {
  --clr-primary: #4F46E5;
  --clr-primary-dark: #4338CA;
  --clr-accent: #F59E0B;
  --clr-success: #16A34A;
  --clr-danger: #DC2626;
  --clr-surface: #FFFFFF;
  --clr-border: #E2E8F0;
  --clr-dark: #1E293B;
  --clr-body: #334155;
  --radius: 12px;
  --shadow-card: 0 8px 24px rgba(15, 23, 42, 0.08);
  --space-unit: 8px;
}

Lapisan 1 · token

  • --clr-primary

Nilai-nilai ini yang dibaca lapisan di bawahnya lewat var().

Lapisan 2 — komponen

Komponen tidak menyimpan nilai; ia memanggil token. Karena itu lengkung, bayangan, dan latarnya otomatis ikut kalau token berubah.

.p-kartu {
  box-sizing: border-box;
  padding: 16px;
  background: var(--clr-surface);
  border: 1px solid var(--clr-border);
  border-radius: var(--radius);
  box-shadow: var(--shadow-card);
}

.p-kartu .harga {
  margin: 0 0 16px;
  color: var(--clr-dark);
}

Lapisan 3 — halaman

Halaman menyusun komponen memakai jarak dari token yang sama: gutter antarkartu 24 piksel, yaitu 3 × --space-unit.

.baris-kartu {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

.header-toko {
  padding: 16px;
  background: var(--clr-surface);
  border-bottom: 1px solid var(--clr-border);
}

Dua baris di bawah memakai komponen yang sama persis. Yang berbeda hanya satu baris: --clr-primary ditimpa di dalam pembungkusnya. Tombol, badge, dan tautan langsung mengikuti tanpa satu pun aturan komponen disentuh.

.tema-ganti {
  --clr-primary: #16A34A;
}

Gutter 24 piksel itu 3 × 8 piksel, dan angka 8 piksel datang dari --space-unit, bukan dari selera tiap halaman.

Yang perlu diingat

  • Token di atas, komponen di tengah, halaman di bawah.
  • Mengubah --clr-primary ikut mengubah tombol, badge, dan link di semua halaman.
  • Dua lapisan sisanya, pola dan dokumentasi, dibahas setelah ini.

Inti pembelajaran: lapisan di atas tidak pernah menyimpan nilai sendiri. Begitu satu halaman menulis nilai mentah, ia keluar dari bangunan dan perubahan berikutnya cuma kena sebagian.
