Token Primitif dan Token Semantik: Nilai atau Peran

Token primitif menyebut nilai tanpa konteks — "indigo 600". Token semantik menyebut peran — --clr-danger untuk pesan bahaya. Peran lebih stabil daripada nilai: merek boleh berganti, makna "bahaya" tetap sama. Token ditulis sekali di :root, lalu dikonsumsi lewat var().

Komponen memanggil peran, bukan nilai

Tombol utama membaca --clr-primary; badge bahaya membaca --clr-danger. Nama token menyebut fungsinya, bukan warnanya, jadi anggota tim baru bisa membacanya tanpa membuka palet.

:root {
  --clr-primary: #4F46E5;
  --clr-danger: #DC2626;
}

.btn-utama {
  box-sizing: border-box;
  display: inline-block;
  padding: 8px 16px;
  background: var(--clr-primary);
  color: #FFFFFF;
  border-radius: 12px;
  font-size: 14px;
}

.badge-bahaya {
  background: var(--clr-danger);
  color: #FFFFFF;
}

Disiplin var(): nilai mentah bikin sistem bocor

Kedua panel di bawah dibungkus kelas yang sama, dan kelas itu menimpa --clr-primary menjadi merah. Panel kiri memakai var() sehingga tombolnya ikut berubah; panel kanan menulis #4F46E5 langsung, jadi tombolnya tertinggal di indigo.

.tema-ganti {
  --clr-primary: #DC2626;
}

.tombol-mentah {
  box-sizing: border-box;
  display: inline-block;
  padding: 8px 16px;
  background: #4F46E5;
  color: #FFFFFF;
  border-radius: 12px;
  font-size: 14px;
}
