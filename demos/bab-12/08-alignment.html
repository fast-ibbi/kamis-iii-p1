Alignment: Satu Garis Tak Terlihat yang Menahan Semua

Alignment menempatkan elemen pada garis tak terlihat yang sama. Garisnya tidak pernah digambar di CSS; mata menangkapnya lewat tepi yang sejajar. Hero Tokosaya di bawah disusun di grid 12 kolom selebar 1120 piksel dengan gutter 24 piksel.

Tiga elemen, satu garis kolom pertama

Judul di span 12, paragraf di span 8, dan tombol di span 2. Ketiganya mulai di garis kolom pertama yang sama; garis putus-putus di kiri kotak hanya penggaris bantu.

.grid-12 {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 24px;
}

.span-12 {
  grid-column: span 12;
}

.span-8 {
  grid-column: span 8;
}

.span-2 {
  grid-column: span 2;
}

Sejajar: judul 12 kolom, paragraf 8, tombol 2

Peralatan Kerja Digital untuk Semua

Keyboard, mouse, hingga monitor. Semua yang dibutuhkan meja kerja rapi, dikirim dalam satu pesanan.

Lihat Katalog

Sebelas gutter 24 px memakan 264 px dari lebar 1120 px; sisa 856 px dibagi 12 menjadi 71 piksel per kolom, dan tombol span 2 berukuran 2 × 71 + 24 = 166 piksel. Di halaman demo ini grid mengikuti lebar layar, jadi kolomnya lebih sempit; angka di atas adalah ukuran pada grid 1120 piksel di dek.

Terlalu banyak perataan membuat garisnya hilang

Di versi bawah, judul digeser 24 piksel dan paragraf 40 piksel. Isinya sama, tetapi tepi kirinya tidak lagi satu garis sehingga pemindaian naik-turun jadi lebih lambat.

.hero-acak h3 {
  margin: 0 0 8px 24px;
}

.hero-acak p {
  margin: 0 0 10px 40px;
}

Acak: tiap elemen punya tepi sendiri

Rata kiri atau rata tengah

Paragraf panjang selalu rata kiri: tepi kiri yang lurus membuat mata mudah menemukan awal baris berikutnya. Rata tengah dipakai untuk elemen tunggal, seperti judul pendek atau keterangan di bawah ikon.

.paragraf-tengah {
  text-align: center;
}

.paragraf-kiri {
  text-align: left;
}

Rata kiri

Yang perlu diingat

  • Teks kartu mulai dari garis vertikal yang sama.
  • Paragraf panjang rata kiri; rata tengah hanya untuk elemen tunggal.
  • Jangan mencampur terlalu banyak perataan dalam satu kolom.
  • Kelas perataan cuma alat; disiplin yang menentukan hasilnya.

Inti pembelajaran: garis kolom tidak pernah ditulis di CSS, tetapi ia yang membuat halaman terasa tenang. Menggeser satu elemen saja sudah cukup untuk menghapus garis itu dari mata.
