Hierarki Visual: Satu Tumpuan, Sisanya Penjelas

Pengguna memindai layar dalam hitungan detik, bukan membaca kata demi kata. Hierarki visual mengatur urutan pemindaian itu: satu tumpuan besar lebih dulu, penjelasnya menyusul. Halaman di bawah memakai isi yang sama, hanya hierarkinya yang berbeda.

Tanpa hierarki: semua teks sama besar

Semua baris memakai ukuran, ketebalan, dan warna yang sama, jadi mata tidak tahu harus mulai dari mana — dan tombol promonya justru bukan aksi utama.

.datar h3,
.datar p,
.datar .aksi {
  margin: 0 0 8px;
  font-size: 16px;
  font-weight: 400;
  color: #334155;
}

.datar .aksi {
  text-decoration: underline;
}

Judul 32 px tepat dua kali teks penjelas 16 px; satu lompatan ukuran saja sudah cukup membuat mata berhenti lebih dulu di judul.

Pegasnya: ukuran, ketebalan, warna, posisi, dan jarak

Ukuran saja biasanya belum cukup. Di bawah ini dua judul berukuran sama; yang kedua memakai ketebalan, warna, dan jarak sekaligus, sehingga tumpuannya jauh lebih tegas.

.satu-pegas h3 {
  margin: 0 0 8px;
  font-size: 32px;
  font-weight: 400;
  color: #334155;
}

.empat-pegas h3 {
  margin: 0 0 24px;
  font-size: 32px;
  font-weight: 700;
  color: #1E293B;
}

Yang perlu diingat

  • Hierarki mengarahkan pemindaian, bukan menghias halaman.
  • Pegasnya: ukuran, ketebalan, warna, posisi, dan jarak.
  • Satu pegas biasanya nggak cukup; gabungkan dua atau tiga.
  • Satu halaman sebaiknya punya satu tumpuan utama, bukan lima.

Inti pembelajaran: hierarki adalah keputusan tentang apa yang dibaca pertama. Kalau semua teks sama besar, halaman menyerahkan keputusan itu ke pengguna yang cuma punya beberapa detik.
