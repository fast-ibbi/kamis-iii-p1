Sistem Tipografi: Dua Keluarga Huruf, Dua Peran

Tokosaya memakai dua keluarga huruf. Poppins memikul judul hero, judul halaman, dan judul kartu; Inter memikul subjudul dan paragraf. Keluarga hurufnya digantungkan dari token, bukan ditulis ulang di tiap halaman.

Token keluarga huruf

Bootstrap menangani ukuran dan jarak, sedangkan berkas css/style.css menggantungkan keluarga hurufnya dari token. Di mesin tanpa Poppins dan Inter, keduanya jatuh ke sans-serif — dan yang tetap terlihat membedakan peran adalah ukuran serta bobotnya.

:root {
  --font-heading: 'Poppins', sans-serif;
  --font-body: 'Inter', sans-serif;
}

h1, h2, h3 {
  font-family: var(--font-heading);
}

body, .lead {
  font-family: var(--font-body);
}

Peran tiap simpul

Poppins berbicara, Inter bercerita. Pergantian hurufnya sendiri sudah jadi sinyal hierarki, jadi pembaca tahu mana judul dan mana penjelas tanpa harus membaca ukurannya.

.lead {
  font-size: 20px;
  font-weight: 400;
  color: #334155;
}

.judul-kartu {
  font-size: 15px;
  font-weight: 600;
  color: #1E293B;
}

Disiplin tipografi: panjang baris dan jenjang heading

Paragraf dibatasi 6 kolom — 6 × 71 + 5 × 24 = 546 piksel — karena baris 60 sampai 75 karakter memang selebar itu pada teks 16 piksel. Baris selebar halaman memaksa mata berjalan jauh sebelum kembali ke kiri.

.paragraf {
  max-width: 546px;
  font-size: 16px;
  line-height: 1.7;
}

Yang perlu diingat

  • Satu h1 per halaman.
  • Jenjang heading nggak melompat: h1 ke h2 ke h3.
  • Panjang baris paragraf 60 sampai 75 karakter.
  • line-height paragraf dibiarkan lega.
  • Keterangan kecil memakai Inter 500.
