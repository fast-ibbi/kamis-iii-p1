Memahami Properti position

position mengatur metode penempatan elemen.

static

Posisi normal dalam aliran dokumen. Ini merupakan nilai default.

.box {
  position: static;
}

Kedua contoh pertama diberi pembungkus .d-static dan .d-relative agar bisa tampil bersama. Kotak bergaris putus-putus adalah bayangan posisi normalnya.

posisi normal
position: static

top: 8px dan left: 8px ditambahkan pada contoh ini, tetapi kotak tidak bergeser — nilai bawaan static mengabaikan keduanya.

relative

Elemen tetap menempati tempatnya dalam aliran dokumen, tetapi dapat digeser dari posisi normalnya.

.box {
  position: relative;
  top: 8px;
  left: 8px;
}
posisi normal
bergeser 8 px

Kotak bergeser 8 px ke bawah dan 8 px ke kanan; ruang aslinya tetap dipesan, jadi tetangga tidak ikut bergerak.

absolute

Elemen dikeluarkan dari aliran normal dan diposisikan berdasarkan containing block yang sesuai, sering kali dibentuk oleh ancestor dengan position selain static.

.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
Kartu produk Baru

fixed

Elemen umumnya diposisikan terhadap viewport dan tetap berada di tempat yang sama ketika halaman digulir.

.button-top {
  position: fixed;
  right: 24px;
  bottom: 24px;
}

Tombol di bawah ini memakai position: fixed. Gulirkan halaman: ia tidak ikut bergerak.

sticky

Elemen berperilaku seperti elemen dalam aliran normal sampai mencapai ambang posisi tertentu saat scrolling, lalu dapat menempel dalam batas scroll container yang relevan.

.header {
  position: sticky;
  top: 0;
}
Header sticky — top: 0

Gulirkan panel ini. Header mengalir seperti biasa sampai menyentuh tepi atas panel, lalu menempel di sana.
