Mengendalikan Ukuran dengan min-width dan max-width

Properti ini menentukan batas minimum dan maksimum lebar elemen.

min-width

Menentukan lebar minimum elemen.

.card {
  min-width: 240px;
}

Elemen tidak akan menyusut di bawah 240 px akibat perhitungan ukuran normalnya, meskipun konten atau container yang sempit dapat menimbulkan overflow.

min-width 240 px di dalam bingkai 200 px

Bingkai 200 px, elemen tetap 240 px — kelebihannya menjadi overflow, bukan penyusutan.

max-width

Menentukan lebar maksimum elemen.

.container {
  width: 100%;
  max-width: 880px;
  margin-inline: auto;
}
width 100% dibatasi max-width 880 px, dipusatkan margin-inline: auto

Panggung 900 px, container berhenti di 880 px, sisa 20 px menjadi margin kiri dan kanan. Di slide angkanya 1240 px dan 1200 px; di sini keduanya diperkecil agar muat di kolom halaman, dan perilakunya sama.

Manfaat

  • Container dapat mengikuti lebar layar.
  • Lebarnya tidak akan melebihi 880 px.
  • Margin otomatis membantu memusatkan container ketika tersedia ruang.
