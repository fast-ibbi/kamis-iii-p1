Perbedaan Padding dan Margin

Keduanya sama-sama mengatur jarak, tetapi memiliki fungsi berbeda.

PropertiFungsiLokasi
paddingMemberikan ruang di dalam elemenDi antara content dan border
marginMemberikan jarak dari elemen lainDi luar border
borderMembentuk garis pembatasMengelilingi content dan padding

Kode

.card {
  padding: 20px;
  margin: 16px;
  border: 2px solid steelblue;
}

Hasil

Konten

padding 20 px × 2 sisi = 40 px tambahan ukuran kotak; margin 16 px tidak menambah ukuran kotak

Penjelasan

  • Konten memiliki ruang tambahan 20 px di setiap sisi.
  • Border memiliki ketebalan 2 px.
  • Elemen memiliki jarak luar 16 px di setiap sisi.

Kapan digunakan?

  • Gunakan padding agar isi elemen tidak menempel pada tepinya.
  • Gunakan margin untuk mengatur jarak antarkomponen.
