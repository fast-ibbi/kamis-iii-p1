Studi Kasus: Membuat Kartu Produk

Gabungkan Box Model, batas ukuran, display, dan skala jarak untuk membangun komponen kartu.

Struktur HTML

<div class="product-card">
  <span class="product-badge">Baru</span>
  <h2>Nama Produk</h2>
  <p>
    Deskripsi produk yang dapat memuat teks panjang
    tanpa merusak layout.
  </p>
  <button>Beli Sekarang</button>
</div>

Kerangka kartu

*,
*::before,
*::after {
  box-sizing: border-box;
}

.product-card {
  position: relative;
  width: 100%;
  max-width: 320px;
  min-height: 220px;
  padding: 24px;
  border: 1px solid #ccc;
  margin: 16px;
}

Isi kartu

.product-badge {
  display: inline-block;
  padding: 8px;
}

.product-card p {
  overflow-wrap: anywhere;
}

.product-card button {
  display: inline-block;
  padding: 8px 16px;
}

Badge

.product-badge {
  position: absolute;
  top: 8px;
  right: 8px;
  z-index: 1;
}

Hasil

Baru

Nama Produk

Deskripsi produk yang dapat memuat teks panjang tanpa merusak layout: https://tokosaya.example.com/katalog/produk/2025/11/kategori-perlengkapan-rumah

lebar content = 320 − (24 × 2) − (1 × 2) = 270 px

tinggi content = 220 − (24 × 2) − (1 × 2) = 170 px

ruang yang ditempati = 320 + (16 × 2) = 352 px

Hasil yang diharapkan

  • Lebar kartu tidak melebihi 320 px.
  • Padding dan border sudah termasuk dalam perhitungan lebar.
  • Tinggi minimum kartu adalah 220 px.
  • Badge berada di sudut kanan atas kartu.
  • Teks panjang dapat membungkus ketika diperlukan.
  • Jarak komponen mengikuti skala kelipatan 8 px.
