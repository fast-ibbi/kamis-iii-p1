Praktikum: Halaman Katalog Tokosaya

Halaman katalog dirakit dari komponen yang sudah dilatih: navbar tanpa JavaScript, breadcrumb, grid kartu, empat variant badge, dan pagination visual. Seluruhnya HTML dan CSS murni — tidak ada satu baris JavaScript.

Urutan empat link di head

1. ../_vendor/bootstrap.min.css        Bootstrap 5.3.3
2. ../_vendor/bootstrap-icons.min.css  Bootstrap Icons 1.11.3
3. Google Fonts                        keluarga huruf Tokosaya
4. css/style.css                       kustom Tokosaya

Urutan ini mengikuti kaskade yang dipelajari di Bab 3: yang ditulis belakangan menang saat kekuatannya setara. Karena itu css/style.css ditaruh paling akhir — supaya aturan kustom bisa menimpa gaya umum Bootstrap tanpa perlu !important.

Kartu KX-210 ditulis penuh sekali, lalu disalin untuk tujuh produk sisa. Yang berubah hanya gambar, badge, judul, kategori, deskripsi, dan harga — pola kelasnya tetap.

Gaya kustom Tokosaya

/* kustom — kartu produk Tokosaya */
.produk-card {
  border: 1px solid var(--clr-border);
  border-radius: var(--radius);
  box-shadow: var(--shadow-card);
  overflow: hidden;
}
/* kustom — kartu mengangkat sedikit pas diarahkan */
.produk-card:hover {
  transform: translateY(-4px);
}

Tiga aturan kustom pelengkap: token warna di :root, kelas .font-heading untuk huruf judul, dan .produk-card di atas. Semua aturan kustom ditandai komentar kustom supaya mudah dibedakan dari gaya bawaan Bootstrap. overflow: hidden yang memotong gambar mengikuti radius kartu.

Di proyek asli, empat menu mengarah ke index.html, katalog.html, tentang.html, dan kontak.html. Di folder demo ini semuanya diarahkan ke berkas demo yang ada supaya tidak ada tautan mati.

Cek daftar katalog.html

  • Navbar gelap: merek di kiri, empat link mendatar, keranjang berikon.
  • Tanpa satu pun tombol navbar-toggler di halaman.
  • Delapan kartu dalam grid row g-4 dengan tinggi seragam.
  • Empat variant badge dipakai sesuai makna semantik.
  • Pagination visual: "1" aktif dan panah kiri pudar.
  • Ikon dekoratif memakai aria-hidden="true".
  • Harga berformat Rp650.000 tanpa spasi.
