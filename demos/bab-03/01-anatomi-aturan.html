Anatomi Blok Aturan: Selector dan Blok Deklarasi

CSS bekerja dengan mencocokkan selector ke elemen HTML. Satu blok aturan selalu berbentuk sama — selector, lalu blok deklarasi berisi pasangan properti dan nilai — dan istilah di halaman ini dipakai terus sampai bab-bab berikutnya.

Blok aturan dan bagian-bagiannya

Contoh dari deck ditulis untuk elemen h1. Judul halaman ini memakai aturan yang sama, jadi tampil 32 px dan berwarna #1E293B.

/* Satu blok aturan: selector h1 dan blok deklarasinya */
h1 {
  color: #1E293B;
  font-size: 32px;
}
h1 {
  color: #1E293B;
  font-size: 32px;
}

selectorpropertinilai

Tiap deklarasi ditutup titik koma, termasuk yang paling akhir. Tanpa titik koma, deklarasi yang ditambahkan sesudahnya menyambung ke nilai sebelumnya dan aturan itu berhenti bekerja sebagaimana mestinya.

Satu selector, banyak elemen

Selector p cocok dengan semua paragraf, bukan satu saja. Aturan berikut menyentuh dua paragraf di kotak demo sekaligus — dan semua paragraf lain di halaman ini, termasuk paragraf yang sedang kamu baca.

p {
  color: #334155;
}

Paragraf pertama di dalam kotak demo.

Paragraf kedua di dalam kotak demo.

Browser tidak menjalankan CSS dari atas ke bawah seperti program. Ia mengumpulkan aturan, mencocokkan tiap selector ke pohon elemen HTML, lalu memakai hasilnya. Satu aturan bisa melayani berapa pun elemen yang cocok.

Titik koma dan heksadesimal enam digit

Proyek Tokosaya konsisten memakai kode heksadesimal enam digit, bukan nama warna. Nilai berikut muncul berulang di seluruh bab.

  • Selector — bagian sebelum {, penentu elemen mana yang kena.
  • Blok deklarasi — isi di antara { dan }.
  • Deklarasi — satu pasangan properti: nilai;.
  • Nilai — #1E293B, 32px, atau nama warna seperti red.

Inti pembelajaran: satu aturan menangani banyak elemen karena browser mencocokkan selector, bukan menjalankan baris kode.
