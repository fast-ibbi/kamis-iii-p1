Tiga Selector Dasar: Elemen, Class, dan ID

Selector elemen menyasar semua elemen bertipe itu, class menyasar gaya yang dipakai ulang, dan ID menyasar satu titik jangkar per halaman. Kalau gaya itu bakal muncul lagi di tempat lain, yang dibutuhkan adalah class.

Selector elemen — semua elemen bertipe itu

Satu aturan untuk seluruh paragraf di halaman. Selector elemen tidak melihat konteks, jadi paragraf di footer pun ikut berubah.

p {
  color: #334155;
}

Paragraf pertama di kotak demo, sewarna dengan paragraf mana pun di halaman ini.

Paragraf kedua, kena aturan yang sama.

Selector class — gaya yang dipakai ulang

Class ditulis dengan titik di depan namanya dan dipasang lewat atribut class. Elemen yang berbeda tipe bisa berbagi satu class selama perannya sama.

.hero-title {
  color: #4F46E5;
}

Judul hero di Beranda

Kalimat pembuka hero, memakai class yang sama.

Selector ID — satu titik jangkar per halaman

ID ditulis dengan tanda pagar dan dipasang lewat atribut id. Satu nilai id hanya boleh muncul sekali dalam satu halaman, jadi ia dipakai untuk jangkar, bukan untuk gaya yang berulang.

#pengantar {
  background-color: #F8FAFC;
  border: 1px solid #E2E8F0;
}

Paragraf ber-id pengantar: latarnya panel dan tepinya bergaris.

Paragraf tetangga tanpa id: tampil biasa.

Memilih di antara ketiganya

SelectorPenulisanJangkauanContoh Tokosaya
elemenp, h1, asemua elemen bertipe ituwarna dasar paragraf
class.hero-titleelemen mana pun yang memakai class itutombol yang muncul di tiga halaman
ID#pengantarsatu elemen per halamanjangkar bagian pengantar

“Kalau gaya itu bakal muncul lagi di tempat lain, yang kamu butuh adalah class.”

Inti pembelajaran: class untuk gaya yang berulang, ID untuk yang benar-benar cuma satu.
