Lima Satuan CSS dan Acuannya

px mengacu pada nilai tetap, % pada kotak induk, em pada font elemen itu sendiri, rem pada font elemen akar, dan vw atau vh pada viewport. Kelimanya alternatif, bukan bertingkat.

px dan rem — nilai tetap lawan ikut font akar

px tidak mengacu ke apa pun; nilainya tetap. rem mengacu pada font-size elemen akar, lazimnya 16px, jadi 1rem = 16px dan 2rem = 32px.

.kotak-px {
  width: 320px;
}

.judul-px {
  font-size: 32px;
}

.kotak-rem {
  width: 20rem;
}

.judul-rem {
  font-size: 2rem;
}
width: 320px
width: 20rem

32 px dari .judul-px

2 rem dari .judul-rem

Selama font akar 16 px, 20rem sama dengan 320 px — dua kotak di atas berukuran persis sama.

Begitu pula 2rem sama dengan 32 px. Kalau pengguna memperbesar font dasar browser, dua nilai rem itu ikut membesar, sedangkan dua nilai px tidak.

em — ikut font elemen itu sendiri

em mengacu pada ukuran font elemen yang memakainya. Karena itu em yang bersarang bisa menumpuk: tiap tingkat mengalikan ukuran tingkat di atasnya.

.teks-em {
  font-size: 1.5em;
}

Tingkat 1: 1.5em Tingkat 2: 1.5em Tingkat 3: 1.5em

Dari dasar 16 px, tingkat pertama jadi 24 px.

Tingkat kedua jadi 36 px, dan tingkat ketiga 54 px. Itu sebabnya rem lebih aman untuk ukuran font.

% — ikut kotak induk

Persentase dihitung dari lebar atau tinggi kotak induk, bukan dari viewport.

.induk-persen {
  width: 400px;
}

.kotak-persen {
  width: 50%;
}
induk: width: 400px
anak: width: 50%

Anak mengisi separuh induknya: 200 px, diukur dari kotak induk yang lebarnya 400 px. Kalau induknya menyempit, anaknya ikut menyempit.

vw dan vh — ikut viewport

1vw adalah 1/100 lebar viewport, 1vh adalah 1/100 tingginya. Karena bergantung penuh pada layar, keduanya tidak dipakai untuk ukuran font.

.banner-vw {
  width: 30vw;
}

.banner-vh {
  height: 30vh;
}
width: 30vw
height: 30vh
