style.css v1 Tokosaya: Satu File Gaya untuk Dua Halaman

Praktik bab ini menghasilkan satu berkas css/style.css yang dipakai index.html dan tentang.html. Tujuannya bukan membuat halaman terlihat cantik, melainkan membuat gaya tinggal di satu tempat.

Langkah praktikum

  1. Buka folder proyek tokosaya-css/ dari Bab 2.
  2. Buat folder css, lalu berkas style.css di dalamnya.
  3. Tambahkan kail class pada elemen utama index.html.
  4. Tautkan link yang sama di index.html dan tentang.html.
  5. Tulis aturan untuk body, heading, link, header, hero, bagian konten, dan footer.
  6. Muat ulang di browser, lalu periksa panel Styles di DevTools.

Kail class di index.html

HTML membawa identitas peran, CSS membawa keputusan visual. Halaman Katalog dan Kontak masih memakai tautan kosong karena belum dibuat; di demo ini semua tautan menunjuk ke berkas ini sendiri.

<header class="site-header">
  <p class="brand">Tokosaya</p>
  <nav class="site-nav" aria-label="Navigasi utama">
    <a href="index.html">Beranda</a>
    <a href="katalog.html">Katalog</a>
    <a href="tentang.html">Tentang</a>
    <a href="kontak.html">Kontak</a>
    <a href="#" class="nav-cart">Keranjang</a>
  </nav>
</header>
<main>
  <section class="hero">
    <h1 class="hero-title">Peralatan Kerja Digital untuk Semua</h1>
    <a href="#" class="btn-cta">Lihat Katalog</a>
  </section>
</main>

Isi style.css v1

Komentar kepala berkas dan komentar bagian menandai isi file. Urutannya mengikuti anatomi halaman: dasar, header, isi, footer.

/* ---------- Tokosaya style.css — v1 (Bab 3) ---------- */

/* ---------- Dasar halaman ---------- */
body {
  margin: 0;
  font-family: 'Segoe UI', Tahoma, Verdana, sans-serif;
  color: #334155;
  background-color: #F8FAFC;
  line-height: 1.6;
}

/* ---------- Heading ---------- */
h1, h2, h3 {
  color: #1E293B;
  line-height: 1.25;
  margin: 0 0 16px;
}

body ditulis paling awal, bukan paling akhir: urutan penulisan ikut menentukan pemenang saat specificity setara, jadi gaya global ditaruh di depan supaya hasilnya bisa diprediksi.

Ukuran heading bertingkat

Heading memakai rem dengan ukuran bertingkat 36 px, 28 px, dan 20 px selama font akar 16 px.

h1 {
  font-size: 2.25rem;
}

h2 {
  font-size: 1.75rem;
}

h3 {
  font-size: 1.25rem;
}

Judul: 36 px — aturan ini yang membuat h1 halaman ini tampil sebesar itu.

Subjudul: 28 px, dan heading tingkat tiga 20 px.

Keadaan link

Link berwarna indigo, menggelap saat kursor di atasnya, dan memberi kotak fokus saat ditabrak tombol Tab.

a {
  color: #4F46E5;
}

a:hover {
  color: #4338CA;
}

a:focus {
  outline: 2px solid #4F46E5;
}

Tautan contoh — arahkan kursor untuk melihat warna menggelap, lalu tekan Tab untuk kotak fokusnya.

Hasil yang diharapkan

  • Teks tampil sans-serif dengan jarak baris 1.6.
  • Heading tegas #1E293B dengan ukuran bertingkat: 36 px, 28 px, 20 px.
  • Latar halaman #F8FAFC dengan panel putih dan garis #E2E8F0.
  • Link indigo #4F46E5, menggelap ke #4338CA saat di-hover.
  • Kotak fokus indigo muncul saat ditabrak tombol Tab.
  • Satu berkas style.css yang sama menata kedua halaman.

Kalau ada yang hasilnya belum berubah, curigai jalur link salah dulu sebelum menuduh kodenya salah. Lakukan muat ulang paksa kalau browser masih memakai berkas gaya dari cache.

Inti pembelajaran: tampilan boleh berubah, tapi keputusannya harus tinggal di satu tempat yang jelas.
