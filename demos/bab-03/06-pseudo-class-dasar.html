Lima Pseudo-Class Dasar Tanpa JavaScript

Pseudo-class menata keadaan elemen: kursor yang berada di atasnya, fokus keyboard, dan posisinya sebagai anak pertama, terakhir, atau bernomor tertentu. Semuanya ditangani murni oleh CSS.

:hover dan :focus — keadaan interaktif

Penulisannya menempel tanpa spasi, misalnya a:hover. :hover menyala saat kursor berada di atas elemen; :focus menyala saat elemen menerima fokus keyboard.

.site-nav a:hover {
  color: #4F46E5;
}

.site-nav a:focus {
  outline: 2px solid #4F46E5;
}

Arahkan kursor ke salah satu tautan, lalu tekan Tab berulang-ulang untuk memindahkan fokus.

Perhatikan bedanya: :hover butuh kursor mouse, sedangkan :focus bisa dicapai tombol Tab. Keduanya ditangani murni oleh CSS, tanpa satu baris JavaScript pun.

:first-child, :last-child, dan :nth-child() — keadaan posisi

Ketiganya menyala karena posisi anak di dalam induknya, bukan karena sentuhan pengguna. :nth-child() menerima pola urutan: odd, even, atau 2n.

.menu-list li:first-child {
  font-weight: 600;
}

.menu-list li:last-child {
  color: #DC2626;
}

.menu-list li:nth-child(odd) {
  background-color: #F8FAFC;
}

Butir pertama menebal, butir terakhir berwarna perhatian, dan butir bernomor ganjil berlatar lembut. Tidak ada class tambahan yang dipasang di tiap butir.

Inti pembelajaran: keadaan elemen bisa ditata tanpa JavaScript, cukup dengan selector yang menempel pada elemen.
