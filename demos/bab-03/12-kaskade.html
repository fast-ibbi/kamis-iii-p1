Kaskade: Siapa yang Menang Saat Aturan Bertabrakan

Kaskade adalah cara browser memutuskan pemenang ketika beberapa aturan menyasar elemen yang sama. Gaya bawaan browser selalu di bawah aturan yang kita tulis, dan kalau aturan setara, yang ditulis paling akhir yang menang.

Gaya bawaan browser selalu di bawah

Tautan di luar aturan kita lahir dari browser sebagai biru tua bergaris bawah. Aturan kita menang: .site-nav a membuat tautan di navigasi menjadi indigo.

.site-nav a {
  color: #4F46E5;
}

Tautan tanpa aturan kita — biru tua bergaris bawah, gaya bawaan browser.

Beranda Katalog Tentang

Gaya bawaan browser — user-agent — adalah lapisan paling bawah dan selalu kalah dari aturan yang kita tulis.

Kalau setara, yang ditulis paling akhir menang

Dua class berikut menetapkan warna berbeda untuk elemen yang sama. Yang menentukan adalah urutan penulisan aturan di dalam berkas, bukan urutan nama class di atribut.

.urutan-satu {
  color: #DC2626;
}

.urutan-dua {
  color: #4F46E5;
}

class ditulis “urutan-satu urutan-dua”: tampil indigo.

class ditulis “urutan-dua urutan-satu”: tetap indigo.

Kedua paragraf tampil indigo karena .urutan-dua ditulis belakangan di dalam berkas. Menukar urutan nama class di HTML tidak mengubah apa pun.

!important: surat keputusan darurat

Tanda ini dipasang pada satu deklarasi dan membuatnya menang atas urutan penulisan. Aturan baru yang ditulis sesudahnya tidak bisa mengalahkannya tanpa tanda yang sama.

.darurat {
  color: #DC2626 !important;
}

.darurat-baru {
  color: #16A34A;
}

Dua class ini sama kuat, tetapi !important membuat warnanya tetap merah.

!important bukan sumber aturan keempat; ia cuma penanda pada aturan kita. Sah dipakai, tetapi jangan jadi kebiasaan — aturan berikutnya jadi makin susah diatur.

Alur keputusan kaskade

LangkahYang dikerjakan
1. Kumpulkansemua aturan yang menyasar elemen itu
2. Saring asalgaya bawaan browser di bawah aturan yang kita tulis
3. Specificityinline, id, class, lalu elemen
4. Urutan tuliskalau semuanya setara, aturan yang ditulis paling akhir menang

Langkah 3 dan 4 paling sering bikin bingung saat pertama belajar: urutan penulisan baru dipakai kalau kekhususannya setara.

Inti pembelajaran: CSS yang terasa berantakan biasanya bukan karena propertinya salah, tapi karena kaskadenya belum dipahami.
