Menata Keadaan Link: Umpan Balik Tanpa JavaScript

Tanpa umpan balik, orang ragu tautannya bisa diklik. Gaya fokus jangan dihapus: bagi pengguna keyboard, kotak fokus itulah pengganti kursor.

Umpan balik saat kursor dan fokus

Tautan diberi warna identitas, lalu digelapkan saat kursor berada di atasnya. Fokus keyboard diberi kotak garis supaya posisi pengguna selalu terlihat.

.site-nav a {
  color: #4F46E5;
}

.site-nav a:hover {
  color: #4338CA;
}

.site-nav a:focus {
  outline: 2px solid #4F46E5;
}
Beranda Katalog Tentang Kontak

Arahkan kursor untuk melihat warna menggelap, lalu tekan Tab untuk melihat kotak fokus.

Gaya fokus jangan dihapus

Menghapus outline membuat tampilan terlihat lebih bersih, tetapi pengguna keyboard kehilangan satu-satunya isyarat posisi mereka. Dua navigasi berikut bisa dibandingkan dengan menekan Tab berulang-ulang.

.tanpa-fokus a:focus {
  outline: none;
}

Beranda Katalog

Spasi mengubah arti: a :hover

Menulis a :hover dengan spasi bukan salah ketik yang tidak berakibat. Spasi berarti “di dalam”, jadi aturan itu menyasar keturunan tautan, bukan tautannya sendiri.

.site-nav a :hover {
  color: #DC2626;
}
Beranda Katalog baru

Arahkan kursor ke kata “baru”: hanya kata itu yang memerah. Arahkan ke “Katalog”: tidak ada yang berubah, karena aturan tadi tidak menyasar tautannya.

Inti pembelajaran: dua pseudo-class ini yang membuat tautan terasa bisa diklik dan bisa dijangkau tanpa mouse.
