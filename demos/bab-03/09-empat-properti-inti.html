Empat Properti Inti Visual

color mengatur tinta teks, background-color mengatur latar kotak, border menggabungkan tebal, gaya, dan warna tepi, sedangkan opacity mengatur transparansi. Keempatnya fondasi; jarak dan layout menyusul di bab berikutnya.

Empat properti dan fungsinya

PropertiFungsiNilai contoh
colorwarna tinta teks dan dekorasi garis#4F46E5, red, rgb(79, 70, 229)
background-colorwarna latar kotak elemen#F8FAFC
bordertebal, gaya, dan warna tepi sekaligus1px solid #E2E8F0
opacitytransparansi, nilai 0 sampai 10.95

Satu aturan, tiga properti

Badge “Tersedia” memakai teks putih di atas hijau sukses, dengan tepi tipis yang memisahkannya dari panel putih di belakangnya.

.badge-tersedia {
  color: #FFFFFF;
  background-color: #16A34A;
  border: 1px solid #E2E8F0;
}
Tersedia teks #FFFFFF di atas #16A34A, tepi 1px solid #E2E8F0

opacity: 0.95 dan 0

Nilai 0.95 membuat badge sedikit menembus latar. Nilai 0 membuatnya benar-benar tak terlihat, walaupun ruangnya tetap dipesan di halaman.

.badge-samar {
  color: #FFFFFF;
  background-color: #16A34A;
  border: 1px solid #E2E8F0;
  opacity: 0.95;
}

.badge-hilang {
  color: #FFFFFF;
  background-color: #16A34A;
  border: 1px solid #E2E8F0;
  opacity: 0;
}
opacity 0.95 opacity 0 badge kedua tidak terlihat, tetapi tempatnya masih memakan ruang.

Catatan

Proyek ini konsisten memakai heksadesimal enam digit, karena Bab 4 nanti mengubah nilai-nilai itu menjadi design token. Perlu diingat juga bahwa background-color tidak diwariskan ke elemen anak, berbeda dari color.

Inti pembelajaran: empat properti ini cuma fondasi; jarak dan layout menyusul di Bab 5 dan Bab 7.
