Kebiasaan yang Bikin CSS Susah Dirawat

Tiga kebiasaan paling sering muncul di tugas: memakai !important untuk setiap konflik, menulis selector kepanjangan, dan menaruh gaya inline di HTML produksi. Ketiganya bisa diganti dengan satu file gaya dan selector seperlunya.

!important untuk setiap konflik

Kalau setiap konflik diselesaikan dengan !important, aturan berikutnya harus memakai tanda yang sama. Warnanya pun tidak bisa diganti lagi dengan cara biasa.

.tautan-wajib {
  color: #DC2626 !important;
}

.tautan-wajib-baru {
  color: #16A34A;
}

Dua class sama kuat, tetapi hasilnya tetap merah karena !important.

Selector kepanjangan

Dua navigasi berikut tampil sama. Yang kiri memakai selector panjang dengan specificity (1, 1, 3); yang kanan cukup satu class dengan (0, 1, 0).

#navigasi ul li a.tautan {
  color: #4F46E5;
}

.nav-link {
  color: #4F46E5;
}

Aturan pengganti untuk selector kiri butuh specificity minimal sama, jadi selector baru makin panjang. Untuk .nav-link, aturan penggantinya cukup satu class.

Gaya inline di HTML produksi

Gaya inline tidak terlihat di style.css dan menang atas hampir semua aturan lain. Satu baris seperti ini cukup untuk membuat warna identitas tidak berlaku di elemen tersebut.

<p style="color: #DC2626;">Stok terakhir: 2 unit</p>

Stok terakhir: 2 unit

Baris ini tidak memakai atribut style, jadi warnanya ikut aturan halaman.

Kebiasaan buruk dan gantinya

Kebiasaan burukYang dirawat
!important untuk setiap konfliksatu file gaya, biarkan kaskade bekerja
#navigasi ul li a.tautan.nav-link — selector seperlunya
gaya inline di HTML produksisemua keputusan visual tinggal di style.css

“Satu file gaya, selector spesifik seperlunya, biarkan kaskade bekerja sebagaimana mestinya.”

Inti pembelajaran: specificity yang terlalu tinggi membuat aturan susah diganti nanti.
