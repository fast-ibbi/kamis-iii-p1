Kebab-Case: Nama Class Berbasis Peran, Bukan Tampilan

Proyek ini memakai huruf kecil bertanda hubung untuk nama class, dengan pola blok-elemen seperti site-nav, hero-title, dan produk-card. Nama yang baik menunjuk peran elemen, bukan warna atau ukurannya.

camelCase dan kebab-case pada elemen yang sama

Dua kolom berikut memuat elemen yang sama dengan penulisan berbeda. Tampilannya identik; yang membedakan hanya nama class-nya.

.site-nav {
  color: #334155;
}

.hero-title {
  color: #1E293B;
  font-weight: 600;
}

.produk-card {
  padding: 8px 10px;
  border: 1px solid #E2E8F0;
  border-radius: 4px;
  background-color: #F8FAFC;
}

camelCase — tidak dipakai proyek ini

.siteNav

.heroTitle

.produkCard

kebab-case — dipakai proyek ini

.site-nav

.hero-title

.produk-card

Polanya: huruf kecil, kata disambung tanda hubung. Nama berbasis peran menuliskan maksudnya, jadi HTML dan CSS saling menunjuk tanpa dokumentasi tambahan.

Nama berbasis tampilan menyesatkan

Badge “Best Seller” Tokosaya bertulis #1E293B di atas #F59E0B. Kalau class-nya dinamai menurut warnanya, nama itu tidak lagi benar begitu desain berubah.

.merah-kecil {
  color: #4F46E5;
  font-size: 12px;
}

Teks ber-class .merah-kecil — sekarang indigo, bukan merah.

Enam bulan lagi, dari nama .merah-kecil kamu hanya tahu warnanya dulu merah. Perannya tidak terbaca sama sekali.
