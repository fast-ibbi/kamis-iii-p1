Tiga Cara Memasang CSS dan Alasan External Jadi Default

Ada tiga tempat menulis gaya: atribut style di elemen, elemen style di dalam head, dan berkas .css terpisah. Ketiganya sah secara teknis, tetapi hanya satu yang dipakai sebagai pola proyek.

Inline: atribut style pada elemen

Gaya ditulis langsung di elemen HTML. Cepat untuk memperlihatkan konsep, tetapi tidak bisa dipakai ulang dan tidak pernah muncul di style.css.

<ul style="line-height: 1.7; color: #334155;">
  <li>Senin sampai Kamis: 08.00 sampai 16.00</li>
  <li style="color: #DC2626;">Jumat: 08.00 sampai 11.30</li>
</ul>
  • Senin sampai Kamis: 08.00 sampai 16.00
  • Jumat: 08.00 sampai 11.30

Gaya inline menang atas hampir semua gaya lain, susah diaudit, dan tidak bisa dipakai ulang. Aturan berikut memperlihatkan kemenangannya atas sebuah class: paragraf pertama memakai class, paragraf kedua memakai class yang sama ditambah atribut style.

.catatan-inline {
  color: #4F46E5;
}

Paragraf dengan class .catatan-inline: indigo.

Paragraf yang sama ditambah atribut style: merah, apa pun isi class-nya.

Internal: elemen style di dalam head

Aturan ditulis di satu tempat dalam halaman, jadi tidak tersebar di setiap elemen. Jangkauannya tetap satu halaman, dan tidak bisa dipakai halaman lain.

<head>
  <title>Tiga Cara Memasang CSS</title>
  <!-- Cara 2: internal CSS di dalam head -->
  <style>
    p {
      color: #334155;
    }
  </style>
  <!-- Cara 3: external CSS melalui elemen link -->
  <link rel="stylesheet" href="css/style.css">
</head>

Perhatikan urutan di head: style ditulis dulu, link setelahnya. Kalau keduanya menetapkan properti yang sama dengan kekuatan setara, aturan yang ditulis paling belakangan yang menang — jadi meletakkan link di atas style membalik pemenangnya.

External: berkas .css terpisah

Satu berkas gaya dipakai semua halaman lewat <link rel="stylesheet" href="css/style.css">. Elemen link itu menjadi bagian tetap di head setiap halaman proyek, sehingga tidak ada halaman yang tertinggal.

Kenapa external jadi default

Warna identitas Tokosaya diganti dari #4F46E5 jadi #4338CA. Dengan satu style.css, perubahan itu cukup satu baris, lalu index.html, katalog.html, tentang.html, dan kontak.html ikut berubah karena semuanya menarik berkas yang sama lewat link.

Cara lama: empat halaman dikali sepuluh baris gaya sama dengan 40 baris yang harus disunting manual, dan satu halaman yang terlewat langsung tampil beda.

Inti pembelajaran: memisahkan struktur dan tampilan itu soal biaya pemeliharaan, bukan selera.
