Butir Pertama, Terakhir, dan Baris Tabel

Pseudo-class posisi menghilangkan kebutuhan class tambahan pada butir pertama, butir terakhir, atau setiap baris tabel. Satu baris CSS menggantikan class yang harus dipasang berulang.

Anak pertama dan anak terakhir

Dua aturan berikut menyasar butir pinggir daftar tanpa satu pun class tambahan di HTML.

.menu-list li:first-child {
  font-weight: 600;
  color: #1E293B;
}

.menu-list li:last-child {
  color: #DC2626;
}

Butir pertama menebal dan memakai tinta judul; butir terakhir memakai warna perhatian. Kalau daftarnya bertambah atau berkurang, keduanya menyesuaikan sendiri.

Baris ganjil pada isi tabel

Selector :nth-child(odd) diarahkan ke baris isi tabel, bukan ke header. Latar lembut membuat mata mudah menyusuri baris yang panjang.

.statistik-table tbody tr:nth-child(odd) {
  background-color: #F8FAFC;
}
