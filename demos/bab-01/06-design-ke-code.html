Alur Design → Code

Desain yang jelas membuat kode menemukan jalannya, bukan mencarinya sendiri. Alur empat wujud ini adalah alur kerja yang dilatih berulang di seluruh buku.

Empat wujud berurutan

  • Rancangan dari Figma — dibahas di Bab 14, dan di sana perannya membaca rancangan, bukan membuatnya dari nol
  • Struktur — rancangan diuraikan menjadi elemen HTML
  • Rupa — struktur diberi warna, ukuran, jarak, dan layout lewat CSS
  • Komponen — kalau kebutuhan berulang, dipakai komponen siap pakai dari CSS framework
.alur-wujud {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

.wujud {
  box-sizing: border-box;
  flex: 1 1 160px;
  padding: 10px 12px;
  background: #ffffff;
  border: 1px solid #c7d2fe;
  border-radius: 6px;
  font-size: 13.5px;
}

Contoh kecil: lencana Best Seller

Rancangannya sederhana: lencana kecil berwarna amber di pojok kartu Keyboard Mekanis KX-210, teks gelap. Lalu diuraikan menjadi markup dan rupa.

<div class="kartu">
  <span class="lencana">Best Seller</span>
  <h3>Keyboard Mekanis KX-210</h3>
  <p class="harga">Rp650.000</p>
</div>
.kartu {
  box-sizing: border-box;
  width: 260px;
  padding: 12px;
  border: 1px solid #d1d5db;
  border-radius: 8px;
  background: #ffffff;
}

.lencana {
  display: inline-block;
  box-sizing: border-box;

  font-size: 13px;

  text-align: center;
}

Versi padding 12 px, lebar total 122 px.

Lencana pertama: lebar total 114 px, jadi isinya 96 px setelah padding 8 px kiri-kanan dan border 1 px kiri-kanan.

Tingginya 42 px, jadi isinya 24 px — persis content 96 × 24 px pada rancangan.

Kalau padding-nya jadi 12 px, lebarnya 122 px dengan isi yang tetap 96 px.

Tingginya ikut menjadi 50 px. Padding dihitung dua kali, kiri dan kanan.

Di HTML teks lencana cuma satu baris di dalam kartu, di CSS ia diberi latar amber dan sudut membulat. Warna amber dan teks gelap itu urusan CSS, bukan HTML.

Bootstrap kelak menyelesaikannya dengan satu kelas

Bootstrap menyelesaikan lencana ini dengan satu kelas badge. Kalau begitu, kenapa belajar CSS dulu? Biar tahu apa yang kelas itu lakukan dan bisa menyesuaikannya kalau rancangan nggak mengikuti pola standar.

Inti pembelajaran: rancangan → struktur → rupa → komponen. Setiap wujud punya pekerjaan sendiri, dan lencana sekecil ini pun tetap kotak yang punya pita padding dan border.
