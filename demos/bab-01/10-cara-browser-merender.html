Cara Browser Merender Halaman

Empat gerakan yang tidak bisa ditukar. Sebut berurutan dalam empat kata: diterima, disusun, diberi gaya, digambar.

Empat gerakan

1. diterima     dokumen HTML datang dari server atau dari berkas lokal
2. disusun       browser membangun pohon dokumen dari tag yang dibaca
3. diberi gaya   aturan CSS dicocokkan ke elemen pohon itu
4. digambar      hasilnya dilukis ke layar
.alur-render {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}

.langkah-render {
  box-sizing: border-box;
  flex: 1 1 150px;
  padding: 12px;
  background: #ffffff;
  border: 1px solid #c7d2fe;
  border-radius: 6px;
  font-size: 13.5px;
}
langkah 1Diterimadokumen HTML
langkah 2Disusunpohon dokumen
langkah 3Diberi gayaaturan CSS dicocokkan
langkah 4Digambardilukis ke layar

Warna tombol ditentukan pada langkah tiga, saat aturan CSS dicocokkan ke elemen pohon. Urutannya tidak bisa dibalik: pohon harus ada lebih dulu sebelum bisa diberi gaya.

Pohon dokumen

Bentuk yang lahir pada langkah dua inilah yang disebut DOM, dan yang akan kamu lihat di panel Elements.

  • html
    • head
      • meta charset
      • meta viewport
      • title
    • body
      • h1
      • p
<html>
  <head> … </head>
  <body>
    <h1>Andi Pratama</h1>
    <p> … </p>
  </body>
</html>

Pohon ini cukup dipahami sebagai wujud struktur dokumen di dalam browser; istilah DOM dipakai untuk menyebutnya.

Ringkasan

  • Render berjalan berurutan: diterima, disusun, diberi gaya, digambar.
  • Langkah dua menghasilkan pohon dokumen — DOM.
  • Langkah tiga yang menentukan warna, ukuran, dan jarak.
  • Panel Elements memperlihatkan pohon itu apa adanya.

Inti pembelajaran: tampilan yang salah selalu punya baris penyebabnya, karena browser tidak menebak — browser membaca.
