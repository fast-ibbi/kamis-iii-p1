Empat Istilah yang Sering Tertukar

Istilah ini dipakai sehari-hari secara bergantian, termasuk oleh dosen lain, jadi perlu dikunci sekarang. Yang paling sering tercampur: web design, UI, dan UX.

Lima baris pembatas

Satu model, tiga istilah

Ketiganya bukan tiga halaman berbeda, melainkan tiga sudut pandang pada halaman yang sama. Bingkai putus-putus adalah web design, isi putih di dalamnya adalah UI, dan deretan bulat di bawah adalah UX.

.bingkai-design {
  box-sizing: border-box;
  padding: 14px;
  border: 2px dashed #1d4ed8;
  border-radius: 8px;
  background: #eef2ff;
}

.bingkai-ui {
  box-sizing: border-box;
  margin-top: 10px;
  padding: 12px;

  border-radius: 6px;
  background: #ffffff;
}

}

HTML dan CSS bukan istilah desain

HTML dan CSS adalah bahan bangun yang menghidupkan rancangan. Keduanya punya lapisan sendiri yang jelas.

HTML — struktur Heading, paragraf, daftar, gambar, link.
CSS — rupa Warna, huruf, jarak, layout.

Satu kasus untuk diuji

Kasus "sulit menemukan tombol kontak" itu masalah UI atau UX? Jawabannya keduanya: tombolnya ada, tetapi perjalanan menemukannya yang gagal.

Inti pembelajaran: UI adalah tampaknya, UX adalah rasanya, web design menyelaraskan keduanya — dan HTML serta CSS yang membuat ketiganya benar-benar ada di layar.
