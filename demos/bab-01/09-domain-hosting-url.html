Domain, Hosting, dan URL

Tiga istilah yang sering tertukar dalam satu kalimat. Bedanya satu pertanyaan: mana yang berupa nama, mana yang berupa tempat?

Tiga istilah

  • Domain — nama alamat website, mis. tokosaya.id, disewa tahunan
  • Hosting — layanan penyimpan file pada server yang selalu menyala
  • Deployment — menyalin file ke server lalu mengaitkannya dengan domain

Domain adalah nama, hosting adalah tempat file disimpan, dan keduanya disewa terpisah.

Membaca satu alamat

Alamat https://tokosaya.id/katalog.html dibaca dari kiri ke kanan lewat tiga kotak. Label panahnya adalah pemisah aslinya.

Rangkaiannya kembali utuh: satu garis miring sebelum jalur file, bukan dua. Garis miring pembuka jalur itu sudah menjadi label panah, jadi jangan menuliskannya lagi di depan katalog.html.

Jalur relatif

Link <a href="katalog.html"> memakai jalur relatif: dibaca dari folder halaman yang membukanya.

index.html dan katalog.html duduk di folder yang sama, jadi cukup menulis nama berkasnya.

Baris ini baru dipakai serius di Bab 2, saat link antarhalaman mulai ditulis.

Belum perlu dibeli sekarang

Untuk latihan bab ini, domain dan hosting belum dibutuhkan sama sekali: file dibuka langsung dari komputer sendiri. Konsepnya sama, cuma belum dipasang di internet.

Inti pembelajaran: domain itu nama, hosting itu tempat. Alamat yang kita tulis di href adalah jalur file, bukan alamat lengkap.
