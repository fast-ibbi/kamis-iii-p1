Frontend dan Backend: Ruang Kafe dan Dapur

Frontend development adalah pekerjaan membangun bagian website yang dilihat, dibaca, dan diklik pengguna di browser. Front berarti sisi depan yang menghadap pengunjung. Backend mengurus yang tidak dilihat pengunjung, tetapi tanpanya ruang depan cuma berisi pajangan.

Tiga lapisan yang bertumpuk

Tiga elemen di layar — judul besar di atas, foto produk di tengah, tombol di bawahnya — lahir dari tiga lapisan. HTML lapisan paling bawah mengurus struktur, CSS di atasnya memberi tampilan, dan CSS framework di puncak menyumbang komponen siap pakai.

Ketiganya ditempuh berurutan sepanjang semester: HTML dulu, CSS setelahnya, dan CSS framework baru di Bab 9.

Dua ruang: kafe dan dapur

Pengunjung nggak melihat dapur, tapi tanpanya ruang kafe cuma berisi furnitur kosong.

.dua-ruang {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 16px;
}

.ruang {
  box-sizing: border-box;
  padding: 12px;
  border-radius: 6px;
  font-size: 14px;
}

Pelayan adalah pengantar pesan antara browser dan server — permintaan dan respons. Pelayan bukan backend; ia penghubung keduanya.

Frontend mengurus penyajian dan interaksi di layar; backend mengurus penyimpanan data dan aturan bisnis. Keduanya beda jenis tantangan — frontend bukan bagian yang mudah, backend bukan bagian yang canggih.

Ringkasan

  • Frontend adalah wilayah "segala sesuatu yang tampak di layar".
  • Tiga lapisan frontend: HTML, CSS, lalu CSS framework.
  • Backend bekerja di server dengan bahasa server dan basis data.
  • Pelayan pada analogi kafe adalah penghubung, bukan backend.

Inti pembelajaran: analogi ruang kafe dan dapur dipakai ulang di seluruh buku, jadi penting untuk mendarah daging lebih dulu sebelum masuk ke HTML.
