Pola Folder Proyek Tokosaya

Kerapian folder bukan soal selera. Tiga kebiasaan di bawah ini yang membuat link tidak rontok dan perbaikan tidak perlu diulang di setiap halaman.

Pohon folder

folder proyek
├── index.html      beranda
├── katalog.html    daftar produk
├── tentang.html    profil toko
├── kontak.html     formulir
├── css/
│   └── style.css   satu file gaya bersama
└── img/            gambar produk dan logo, berakhiran .svg

Tiga kebiasaan

KebiasaanAlasannya
Satu CSS bersamaPerbaikan di satu tempat menular ke semua halaman
Nama kebab-caseLink tidak rontok karena perbedaan besar kecil huruf antar sistem operasi
Satu halaman satu fileTidak ada dokumen raksasa yang sulit dibaca

Ketiganya terlihat remeh, tetapi masing-masing menutup satu jenis kesalahan yang mahal.

Kebab-case dalam praktik

Nama berkas dan folder ditulis huruf kecil semua, dengan tanda hubung sebagai pemisah. Nama folder profil-mahasiswa dan berkas foto-profil.png pada bab ini mengikuti kebiasaan itu.

profil-mahasiswa/img/foto-profil.png — aman
Profil Mahasiswa/Img/Foto Profil.png — spasi dan huruf kapital: sumber bug link paling umum

Spasi dan huruf kapital pada nama berkas adalah sumber bug link paling umum bagi pemula. Sarannya sama seperti saat praktikum: salin nama berkas, jangan mengetiknya dari ingatan.

Ringkasan

  • Satu CSS bersama, dipakai semua halaman.
  • Nama kebab-case, tanpa spasi dan tanpa huruf kapital.
  • Satu halaman satu berkas, dengan index.html sebagai beranda.
  • css/ dan img/ memisahkan gaya dan gambar dari halaman.

Inti pembelajaran: pola folder adalah keputusan pertama yang menua paling lama — ia diwarisi setiap halaman berikutnya.
