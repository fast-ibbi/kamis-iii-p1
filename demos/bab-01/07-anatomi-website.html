Anatomi Sebuah Website

Empat pengertian yang membentuk satu bangunan. Tanpa keempatnya, "toko di internet" hanya kumpulan berkas yang tidak saling mengenal.

Empat pengertian

  • Halaman (page) — satu dokumen HTML yang menampilkan satu layar konten
  • Website — sejumlah halaman yang saling terhubung lewat link
  • Aset — gambar, file CSS, kadang font dan ikon
  • index.html — file yang dibuka pas pengunjung cuma mengetik tokosaya.id/

Satu website, dilihat dari dekat

Satu Website Tokosaya berisi beberapa Halaman dan sekumpulan Aset. Satu aset seperti style.css dipakai bersama oleh semua halaman.

.website {
  box-sizing: border-box;
  padding: 12px;
  border: 1px solid #9ca3af;
  border-radius: 8px;
  background: #f8fafc;
}

.halaman {
  box-sizing: border-box;
  padding: 10px 12px;
  background: #eef2ff;
  border: 1px solid #c7d2fe;
  border-radius: 6px;
  font-size: 13.5px;
}

.aset {
  box-sizing: border-box;
  padding: 10px 12px;
  background: #fffbeb;
  border: 1px solid #fcd34d;
  border-radius: 6px;
  font-size: 13.5px;
}

Aset style.css dan gambar produk

Mahasiswa sering menyebut gambar sebagai halaman. Gambar adalah aset: ia tidak dibuka sendiri, melainkan dipanggil oleh halaman.

Mengapa namanya index.html

Alamat tanpa nama file dianggap menunjuk halaman utama. Konvensi yang sama bekerja di komputer sendiri saat kita dobel klik index.html. Itulah sebabnya seluruh proyek buku ini memakai nama index.html, bukan utama.html atau halaman1.html.

tokosaya.id/ → dibukakan index.html
tokosaya.id/katalog.html → dibukakan katalog.html

Ganti index.html menjadi utama.html, dan alamat pendek tokosaya.id/ tidak lagi punya halaman utama yang dituju.

Ringkasan

IstilahIsi
HalamanSatu dokumen HTML, satu layar konten
WebsiteSejumlah halaman yang saling terhubung lewat link
AsetGambar, file CSS, kadang font dan ikon
index.htmlHalaman yang dituju alamat pendek tokosaya.id/

Inti pembelajaran: website bukan satu berkas besar, melainkan halaman-halaman yang dihubungkan link dan dilayani bersama oleh aset yang sama.
