grid-template-areas: Denah dengan Kata

grid-template-areas menggambar denah memakai nama area, bukan angka garis. Denahnya bisa dibaca langsung di dalam CSS, seperti membaca sketsa.

Denah satu kolom sebagai titik awal

Tiap baris kata diapit tanda petik, dan jumlah kolom di setiap baris harus sama. Denah di bawah menggambar empat area yang bertumpuk.

.hlm {
  display: grid;
  grid-template-columns: 1fr;
  grid-template-areas:
    "header"
    "nav"
    "main"
    "footer";
}

Kalau salah satu aturan dilanggar — tanda petiknya hilang atau jumlah kolomnya tidak konsisten — browser gagal membentuk denah dan halaman diam-diam kembali ke tumpukan satu kolom.

Butir mengambil posisinya lewat grid-area

Nama di denah baru berarti setelah butirnya menyebut nama itu. Markup tidak berubah: yang berpindah hanya nama area yang dipanggil tiap bagian halaman.

.hlm-header {
  grid-area: header;
}

.hlm-nav {
  grid-area: nav;
}

.hlm-main {
  grid-area: main;
}

.hlm-footer {
  grid-area: footer;
}

Simulasi lebar 375 px — keempat area bertumpuk satu kolom.

header
nav
main — isi halaman tinggal di area ini
footer

Denah yang berubah cukup digambar ulang

Tidak ada satu pun kelas posisi yang perlu ditambahkan ke markup. Denah dua kolom di bawah hanya menulis ulang string areanya di dalam media query.

@media (min-width: 768px) {
  .hlm {
    grid-template-columns: 240px 1fr;
    grid-template-areas:
      "header header"
      "nav main"
      "footer footer";
  }
}

Simulasi lebar 768 px — header dan footer membentang penuh, nav bergeser ke kolom kiri.

header — membentang dua kolom
nav
main — sisa lebar setelah kolom navigasi
footer — membentang dua kolom

Di lebar 768 px, kolom navigasi memakai 240 px dan area main menyisakan 528 px.

Baris pertama denah memuat dua nama: header dua kali untuk dua kolom. Jumlah nama di tiap baris itulah yang harus konsisten.

Bentuk persegi saja

grid-template-areas hanya bisa menggambar bentuk persegi. Bentuk tangga — misalnya kolom yang menggeser satu track di baris kedua — harus disusun dengan garis, memakai grid-column dan grid-row seperti pada berkas sebelumnya.

Inti pembelajaran: denah berbasis kata lebih gampang dirawat daripada hitungan nomor garis, karena bentuk akhirnya terlihat langsung di kode. Yang perlu dijaga hanya dua: tanda petik, dan jumlah kolom yang sama di setiap baris.
