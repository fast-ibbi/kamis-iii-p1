Katalog Responsif

Katalog Tokosaya hanya perlu satu wadah diberi kelas grid. Jumlah kolomnya naik di tiga titik, sedangkan kartunya tetap kartu produk yang sudah dipakai sejak Bab 5 dan 6.

Satu kolom dasar, lalu naik

Denah milik wadah, jadi perubahannya cukup di satu tempat: .katalog-grid. Markup kartu tidak ikut berubah sedikit pun.

.katalog-grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: calc(var(--space-unit) * 3);
}

@media (min-width: 576px) {
  .katalog-grid { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 992px) {
  .katalog-grid { grid-template-columns: repeat(3, 1fr); }
}

@media (min-width: 1200px) {
  .katalog-grid { grid-template-columns: repeat(4, 1fr); }
}

Kedua bingkai ditumpuk supaya sama-sama muat di kolom baca; yang digambarkan adalah dua lebar wadah, bukan jendela yang diubah.

Di bingkai 576 px, satu gap 24 px menyisakan 552 px untuk dua kartu.

Tiap kartu selebar 276 px. Di bingkai 375 px, satu kartu memakai seluruh lebar.

Tiga kolom dan empat kolom

Dua titik berikutnya tidak digambar dalam ukuran sesungguhnya karena tidak muat di kolom baca. Yang ditunjukkan hanya susunannya: tiga kolom mulai 992 px, empat kolom mulai 1200 px.

Di 1200 px, tiga gap memakai 72 px, jadi empat kartu berbagi 1128 px.

Tiap kartu selebar 282 px. Di katalog.html, delapan produk dengan lebar itu tampil sebagai empat kolom dua baris.

  • Satu kolom dasar, lalu dua, tiga, dan empat kolom.
  • Kartu tetap memakai kelas produk-card dari Bab 5 dan 6.
  • Di 1200 px grid jadi empat kolom dua baris.

Kalau tiap kartu diberi kelas kolom sendiri, jumlah kolom harus diubah di sebanyak jumlah kartu. Karena denah milik wadah, jumlah kolom cukup diatur sekali, dan blok media query-nya diletakkan di akhir style.css supaya kaskadenya jelas.

Inti pembelajaran: responsif pada katalog bukan pekerjaan kartu, melainkan pekerjaan wadah. Satu kelas di wadah, tiga blok media query menaik, selesai.
