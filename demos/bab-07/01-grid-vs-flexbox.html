CSS Grid dan Flexbox: Satu Arah atau Dua Arah

CSS Grid adalah modul layout yang membagi wadah menjadi baris dan kolom sekaligus. Flexbox, yang dipakai sejak Bab 6, tetap bekerja; grid hanya menambah kemampuan yang tidak dimiliki flexbox. Halaman ini menaruh isi yang sama pada kedua modul supaya bedanya terlihat.

Flexbox: satu arah, tiap baris mengatur dirinya sendiri

Pada flexbox, butir mengalir sepanjang satu sumbu. Ketika barisnya penuh dan butir menekuk, baris berikutnya mulai lagi dari kiri dengan pembagian ruangnya sendiri.

.baris-flex {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

Enam butir dengan panjang isi berbeda di dalam wadah 720 px.

Lebar butir mengikuti isinya, jadi tepi kanan tiap baris berbeda. Di sinilah flexbox kuat: ia bergerak dari konten menuju layout.

Grid: dua arah, denah ditetapkan lebih dulu

Dengan grid, kita menentukan denahnya dulu, baru menaruh isinya. Tiga kolom selebar sama membuat tepi kolom tetap satu garis dari atas ke bawah, walaupun panjang teks tiap butir berbeda.

.denah-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

Enam butir yang sama, kini di dalam denah tiga kolom.

Satu denah, tiga baris

Denah dua belas kolom memperlihatkan bahwa yang menjaga baris tetap lurus bukan lebar butir, melainkan denah yang sudah ditetapkan lebih dulu. Tiap baris di bawah jumlah kolomnya dua belas.

.denah-12 {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 16px;
}

.baris-penuh {
  grid-column: span 12;
}

.baris-duapertiga {
  grid-column: span 8;
}

.baris-sepertiga {
  grid-column: span 4;
}

.baris-separuh {
  grid-column: span 6;
}

.baris-seperempat {
  grid-column: span 3;
}

Baris pertama span 12; baris kedua span 4 lalu span 8; baris ketiga span 3, span 3, dan span 6.

Baris kedua: 4 + 8 = 12 kolom, penuh satu baris.

Baris ketiga: 3 + 3 + 6 = 12 kolom. Jumlah butirnya berbeda, garis kolomnya sama.

Kapan pakai yang mana

PertanyaanFlexboxGrid
Arah berpikir dari konten menuju layout dari denah menuju konten
Contoh di Tokosaya navigasi horizontal, footer multi kolom, barisan kartu dengan panjang isi berbeda kerangka halaman berisi header, nav, main, dan footer; kartu statistik yang harus sebaris sempurna

Di proyek nyata keduanya dipakai bersama: grid menyusun kerangka halaman, flexbox menata isi tiap sel. Satu kasus sengaja tidak masuk daftar itu — satu elemen yang digeser sedikit dari alurnya — karena itu urusan position di Bab 5, bukan grid atau flexbox.

Inti pembelajaran: grid menyusun dua dimensi sekaligus, jadi pertanyaannya bukan mana yang lebih baik, melainkan apakah masalahnya satu arah atau dua arah.
