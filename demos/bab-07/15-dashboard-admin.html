Praktik: Dashboard Admin Tokosaya

Yang dibangun bukan halaman yang cantik, melainkan dashboard yang tetap terbaca di lima lebar layar. Semua datanya statis, tanpa JavaScript dan tanpa server: satu denah grid, beberapa media query menaik, dan markup yang tidak tersentuh sejak langkah pertama.

Kerangka admin.html

Markup hanya memberi nama bagian. Ia tidak tahu bagian mana yang ada di kiri dan mana yang di kanan, karena posisi adalah urusan CSS.

<div class="dasbor">
  <header class="dasbor-header">
    <p class="dasbor-brand">Tokosaya</p>
    <h1 class="dasbor-judul">Dashboard Admin</h1>
  </header>
  <nav class="dasbor-nav" aria-label="Navigasi panel admin">
    <ul>
      <li><a class="dasbor-tautan aktif" href="admin.html" aria-current="page">Dashboard</a></li>
      <li><a class="dasbor-tautan" href="katalog.html">Katalog</a></li>
    </ul>
  </nav>
  <main class="dasbor-main">...</main>
  <footer class="dasbor-footer">...</footer>
</div>

File: tokosaya-css/admin.html

  • Markup cuma punya satu h1, yaitu judul dashboard.
  • Posisi tiap area ditentukan CSS, bukan markup.
  • Tautan yang sedang aktif diberi aria-current="page" sesuai kebiasaan Bab 2.

Gaya dasar denah dasbor

Gaya dasar ini berlaku untuk semua layar, termasuk HP, dan tidak memuat satu pun media query. Tumpukan satu kolom di sini bukan versi darurat, melainkan keputusan sadar untuk layar kecil.

.dasbor {
  display: grid;
  grid-template-columns: 1fr;
  grid-template-areas:
    "header"
    "nav"
    "main"
    "footer";
  min-height: 100vh;
  background: var(--clr-bg);
  color: var(--clr-body);
  font-family: var(--font-body);
}

File: tokosaya-css/css/admin.css

Media query yang menaik

Dua blok berikut hanya menambah: satu untuk kartu statistik, satu untuk denah dasbor. Markup tidak berubah sama sekali.

@media (min-width: 576px) {
  .stat-kartu {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 768px) {
  .dasbor {
    grid-template-columns: 220px 1fr;
    grid-template-areas:
      "header header"
      "nav main"
      "footer footer";
  }
}

Hasil yang diharapkan

Pada lebar terlebar, denah yang sama memberi hitungan seperti contoh di slide: sidebar melebar jadi 240 px, sehingga area main tinggal 960 px, dan empat kartu dalam satu baris masing-masing 222 px.

Layar 1200 px dikurangi sidebar 240 px menyisakan 960 px untuk area main.

Tiga gap 24 px memakan 72 px, jadi keempat kartu berbagi 888 px.

Maka tiap kartu selebar 222 px — sama lebar, karena 1fr membagi habis sisa ruangnya.

LebarYang terlihat

768 pxnavigasi geser ke kolom kiri selebar 220 px

Perhatikan bahwa yang berubah antar breakpoint hanya string denah dan jumlah kolom; nilai grid-area di tiap elemen tetap sama. Kalau sidebar tidak mau bergeser, curigai jumlah kolom di setiap baris denahnya tidak konsisten.

Inti pembelajaran: satu denah grid dan beberapa media query menaik sudah cukup. Markup tidak pernah disentuh lagi setelah langkah pertama, dan seluruh halaman tetap statis.
