Breakpoint Konvensi Tokosaya

Breakpoint adalah lebar layar tempat gaya berubah. Ia bukan daftar merek HP, karena katalog merek berganti tiap tahun sedangkan tugas pengguna tidak. Angka di bawah dipakai terus sampai Bab 9.

Empat titik naik

Urutan min-width harus menaik, dan tiap titik hanya menambah apa yang berubah di titik itu.

@media (min-width: 576px) {
  .stat-kartu {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 768px) {
  .dasbor {
    grid-template-columns: 220px 1fr;
  }
}

@media (min-width: 992px) {
  .dasbor {
    grid-template-columns: 240px 1fr;
  }
}

@media (min-width: 1200px) {
  .stat-kartu {
    grid-template-columns: repeat(4, 1fr);
  }
}

Lima mode denah

Gambar di bawah menunjukkan susunan areanya, bukan skala piksel. Setiap kotak mewakili satu mode: dari bawaan tanpa media query sampai mode terlebar.

Bawaan, sm 576, md 768, lg 992, xl 1200 — dibaca dari kiri ke kanan; kolom navigasi diberi angka lebarnya.

Isi tiap mode

sm576 pxkartu statistik dua kolom
md768 pxpanel navigasi geser ke kiri, sidebar 220 px

Antara md dan lg sidebar melebar 20 px; hanya satu angka yang berubah, jadi tidak perlu menulis ulang denahnya.

Rentang antara md dan lg 224 px; di dalam rentang itu tidak ada perubahan gaya sama sekali.

Kenapa angkanya begitu

  • Breakpoint lahir dari konten dan tugas pengguna, bukan dari katalog merek HP.
  • Konvensi Bootstrap menutup daftar ini dengan xxl di 1400 px, yang jarang dibutuhkan di proyek sekecil Tokosaya.
  • Pada lebar 820 px, misalnya, yang sedang berlaku adalah md: sudah melewati 768, belum mencapai 992.

Strategi mobile-first sendiri bukan gagasan baru di industri; Wroblewski menjelaskannya pada 2012, dan sampai sekarang polanya masih sama: gaya dasar untuk layar kecil, lalu naik.

Inti pembelajaran: pilih sedikit titik, urutkan menaik, dan pastikan setiap titik punya alasan yang bisa dijelaskan lewat isi halaman — bukan lewat merek perangkat.
