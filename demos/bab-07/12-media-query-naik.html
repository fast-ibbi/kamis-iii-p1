Menulis Media Query Menaik

Media query menempelkan gaya tambahan pada satu rentang lebar layar. Kalau ditulis menaik — dari titik terkecil ke terbesar — tiap blok hanya menambah, dan tidak ada aturan yang perlu dibatalkan.

Satu aturan dasar, satu blok media query

Gaya dasar memberi kartu satu kolom. Blok media query hanya menyebut yang berubah, yaitu jumlah kolomnya; display: grid dan gap diwarisi dari gaya dasar.

.stat-kartu {
  display: grid;
  grid-template-columns: 1fr;
  gap: calc(var(--space-unit) * 3);
}

/* breakpoint pertama: mulai 576 piksel, kartu dua kolom */
@media (min-width: 576px) {
  .stat-kartu { grid-template-columns: repeat(2, 1fr); }
}

Simulasi lebar 375 px — di bawah 576 px, satu kolom.

Simulasi lebar 768 px — sudah melewati 576 px, kartu dua kolom.

Pesanan128
PendapatanRp 12,4 jt
Stok menipis9
Pelanggan baru34

Kedua bingkai ditumpuk supaya muat di kolom baca. Yang digambarkan bukan jendela yang diubah, melainkan dua lebar wadah: 375 px dan 768 px. Pada jendela sungguhan, hasilnya sama asal lebarnya melewati 576 px.

Di bingkai 768 px, satu gap 24 px menyisakan 744 px untuk dua kartu.

Tiap kartu selebar 372 px; di 375 px, kartu yang sama memakai seluruh lebar bingkai.

Titik berikutnya ditulis setelahnya

Blok kedua ditulis sesudah blok pertama, dengan angka yang lebih besar. Kaskade memakai urutan penulisan saat spesifisitasnya sama, jadi blok terakhir yang menang.

@media (min-width: 1200px) {
  .stat-kartu { grid-template-columns: repeat(4, 1fr); }
}
  • Urutan min-width harus menaik: 576, 768, 992, 1200.
  • Kalau urutannya terbalik, blok yang lebih lebar bisa tertimpa blok yang lebih sempit.
  • Proyek sebesar Tokosaya cukup dua sampai tiga breakpoint.

Antara titik pertama dan terakhir ada rentang 624 px; di dalamnya kartu tetap dua kolom karena tidak ada blok yang menyebutnya lagi.

Inti pembelajaran: media query cukup memuat bedanya, dan bloknya harus naik. Kalau sebuah aturan harus ditulis ulang di dalam blok, biasanya gaya dasarnya belum pas.
