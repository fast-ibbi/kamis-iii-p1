## Rincian Pertemuan

### Pertemuan 1 — Pengantar Frontend Development dan Web Design

**Link Slides:** [Bab 1](https://fast-ibbi.github.io/kamis-iii-p1/bab-01-pengantar-frontend-development-dan-web-design) · [PDF](https://fast-ibbi.github.io/kamis-iii-p1/bab-01-pengantar-frontend-development-dan-web-design.pdf)

**Tujuan Pembelajaran:**

1. Menjelaskan definisi dan lingkup kerja *frontend development* serta hubungannya dengan "apa yang dilihat pengguna di layar".
2. Membedakan tanggung jawab *frontend* dan *backend* pada sebuah website berdasarkan pengamatan nyata.
3. Mengidentifikasi posisi frontend dalam alur pengembangan sistem informasi, dari kebutuhan bisnis sampai implementasi, serta peran lulusan Sistem Informasi di dalamnya.
4. Membedakan konsep *web design*, *user interface* (UI), *user experience* (UX), HTML, dan CSS serta menjelaskan alur *design → code*.
5. Mengimplementasikan halaman profil mahasiswa dengan HTML murni (heading, paragraf, gambar, daftar, link) secara valid.
6. Menginspeksi struktur halaman yang ditulis menggunakan Chrome DevTools dan menjelaskan hasil pengamatan.
7. Merancang pola folder proyek web sederhana sesuai konvensi buku ini.

**Praktikum:** halaman `profil-mahasiswa/index.html` (satu `h1`, foto ber-`alt`, `ul` dan `ol`,
link web dan `mailto:`) lalu diinspeksi lewat panel **Elements** dan *device toolbar*.

**Tugas:** Tugas 1 (individu, `index.html` + `rencana.html` saling bertautan) dan Tugas 2
(kelompok 3–4 orang, tabel perbandingan dua website layanan).

## Struktur Repo

```
buku/                      naskah bab (sumber materi slide)
slides/                    deck Marp per bab
├── bab-01-….md            deck Bab 1
├── theme/academic.css     tema slide
├── marp.config.mjs        config saat marp dijalankan dari dalam slides/
└── assets/diagrams/       diagram hasil bake (.svg) + sumber .mmd
marp.config.mjs            config saat marp dijalankan dari akar repo
scripts/build-pages.mjs    melengkapi build: HTML + assets + index.html
.github/workflows/build.yml  deploy otomatis ke GitHub Pages
```

## Alur Kerja

```bash
npm install                  # sekali per klon

# bangun semua deck ke dist/ (PDF + HTML + index.html), lalu deploy ke Pages
npm run build

# lihat slide sambil mengajar (buka dist/<slug>.html, tekan p untuk presenter view)
npm run serve                # server Marp di http://localhost:8080

# hanya PDF (handout)
npm run build:pdf
```

Menulis bab baru: buat `slides/<slug>.md` dengan front-matter `theme: academic`, lalu jalankan
`npm run build`. Setiap deck perlu **catatan penyaji** di tiap slide (komentar HTML) karena itulah
yang tampil di presenter view.

Mengubah diagram: diagram ditulis sebagai blok ` ```mermaid ` lalu di-*bake* menjadi berkas `.svg`.
Setelah mengedit `slides/assets/diagrams/<slug>-NN.mmd`, jalankan ulang proses bake agar SVG-nya
diperbarui.

## Versi

- `@marp-team/marp-cli` 4.5.1 dengan **marp-core 4.4.0** — versi yang menjadi acuan tema, auto-scaling,
  dan fragment pada repo ini. Jangan naikkan ke marp-core v5 tanpa memeriksa ulang tema.
- Tema memakai *system font stack* agar tidak ada permintaan jaringan saat render offline.
