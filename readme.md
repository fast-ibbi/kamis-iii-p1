satu proyek berjalan (studi kasus **Tokosaya**), HTML dan CSS murni tanpa JavaScript.

- **Semester:** III · kelas Kamis
- **Pertemuan:** 16 bab (Bab 8 UTS, Bab 16 UAS)
- **Program Studi:** Sistem Informasi / Teknik Informatika

- **Proyek buku:** `tokosaya-css/` (Bab 1–8) dan `tokosaya-bootstrap/` (Bab 9–16)
- **Studi kasus:** Tokosaya — toko online UMKM, _"Belanja Tepat, Kirim Cepat"_

### Pertemuan 1 — Pengantar Frontend Development dan Web Design

**Link Slides:** [Bab 1](https://fast-ibbi.github.io/kamis-iii-p1/bab-01-pengantar-frontend-development-dan-web-design) · [PDF](https://fast-ibbi.github.io/kamis-iii-p1/bab-01-pengantar-frontend-development-dan-web-design.pdf)

**Tujuan Pembelajaran:**

1. Menjelaskan definisi dan lingkup kerja _frontend development_.
2. Membedakan tanggung jawab _frontend_ dan _backend_ pada sebuah website.
3. Menempatkan frontend dalam alur pengembangan sistem informasi.
4. Membedakan _web design_, UI, UX, HTML, dan CSS serta alur _design → code_.
5. Menulis halaman HTML pertama, menginspeksinya, dan menata folder proyek.

**Praktikum:** halaman `profil-mahasiswa/index.html` dengan subfolder `img/` berisi
`foto-profil.png`. Yang wajib teramati di DevTools: panel **Elements** memperlihatkan
`html > head > meta` dan `body` berisi `h1`, `img`, `p`, serta `ul`/`ol`; mengklik baris elemen
menyorot kawasan elemen itu di halaman; _device toolbar_ menjalankan lebar dari sekitar 360 px
ke layar meja. Catat tiga baris setiap kali DevTools dibuka: apa yang dilihat, di panel apa,
apa artinya bagi kode.

**Tugas:** Tugas 1 (individu) `index.html` dan `rencana.html` yang saling terhubung lewat link;
Tugas 2 (kelompok) tabel perbandingan dua website layanan.

### Pertemuan 3 — Dasar-Dasar CSS

**Link Slides:** [Bab 3](https://fast-ibbi.github.io/kamis-iii-p1/bab-03-dasar-dasar-css) · [PDF](https://fast-ibbi.github.io/kamis-iii-p1/bab-03-dasar-dasar-css.pdf)

**Tujuan Pembelajaran:**

1. Menjelaskan cara kerja CSS lewat pencocokan selector ke elemen HTML.
2. Membedakan tiga cara pemasangan CSS dan alasan external menjadi default.
3. Memakai selector elemen, class, ID, grouping, dan descendant.
4. Menerapkan pseudo-class dasar untuk keadaan interaktif tanpa JavaScript.
5. Menganalisis konflik gaya dengan specificity dan urutan penulisan.
6. Merancang struktur `style.css` yang terorganisasi dan konsisten.

**Praktikum:** membuat folder `css/` dan `style.css`, memasang kail class pada elemen utama
`index.html`, memasang `<link>` yang sama di `index.html` dan `tentang.html`, lalu memeriksa
panel Styles di DevTools.

**Tugas:** menerapkan `style.css` v1 ke `index.html` dan `tentang.html`, plus catatan 150 kata
berisi tiga keputusan warna beserta alasannya.

### Pertemuan 4 — Tipografi dan Visual Design CSS

**Link Slides:** [Bab 4](https://fast-ibbi.github.io/kamis-iii-p1/bab-04-typography-dan-visual-design-css) · [PDF](https://fast-ibbi.github.io/kamis-iii-p1/bab-04-typography-dan-visual-design-css.pdf)

**Tujuan Pembelajaran:**

1. Peran tipografi untuk keterbacaan, identitas, dan pengalaman pengguna.
2. Google Fonts Poppins dan Inter dengan fallback stack yang aman.
3. Properti tipografi dasar dan skala rem dengan `clamp()`.
4. Sistem warna Tokosaya dengan warna semantik dan ambang kontras WCAG.
5. `border-radius`, `box-shadow`, `opacity`, serta background solid atau gradient.

teks dan navbar statis, hero (judul, subjudul, tombol "Lihat Katalog"), section `#produk`
berisi grid delapan kartu, section CTA bergradien, dan footer kontak; lalu menulis `:root`
lengkap beserta reset ringkas.

**Tugas:** Tugas kelompok 3–4 orang — menyusun palet alternatif Tokosaya memakai struktur token
`:root` yang sama, plus tabel kontras minimal empat baris.

### Pertemuan 5 — CSS Box Model dan Layout

**Link Slides:** [Bab 5](https://fast-ibbi.github.io/kamis-iii-p1/bab-05-css-box-model-dan-layout) · [PDF](https://fast-ibbi.github.io/kamis-iii-p1/bab-05-css-box-model-dan-layout.pdf)

**Tujuan Pembelajaran:**

1. Anatomi box model: content, padding, border, margin.
2. Hitungan lebar total kotak di content-box dan border-box.
3. Pemasangan `box-sizing: border-box` global dan alasannya.
4. Perilaku display: block, inline, dan inline-block.
5. Penanganan overflow dan pemenggalan teks panjang.
6. Position, z-index, dan sistem jarak skala 8px.

**Praktikum:** menulis ulang `index.html` (hero dan delapan kartu) dan `css/style.css` (token,
reset, komponen); memastikan aturan `box-sizing` ada di paling atas setelah token; memeriksa
diagram kotak `.produk-card` di DevTools, termasuk mematikan `box-sizing` sebentar untuk
melihat pembeda `content-box` dan `border-box`.

**Tugas:** menyusun `tokosaya-css/statistik.html` berisi panel "Ringkasan Tokosaya" — empat
kotak statistik berderet `inline-block`, seluruh jarak dari skala 8 px, dan satu badge
`position: absolute`.
